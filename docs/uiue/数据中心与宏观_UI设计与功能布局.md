## 数据中心与宏观 · UI 设计与功能布局规范

> 定位:个人金融投研看板。按"任务"组织信息,而非按数据类型堆放。
> 三类使用场景全覆盖:盘前简报(5 分钟形成当日观点)/ 盘中监控(资金与微观结构)/ 盘后研究(宏观与事件)。
> 视觉基调:深色主题,沿用现有设计语言(涨 emerald / 跌 red / 警示 amber / 背景 gray-900)。

---

### 一、整体框架

```
┌────────────────────────────────────────────────────────────────────┐
│ 市场脉搏 · Market Intelligence          NY 19:41 · HK 07:41 · TYO 08:41 │
│ ┌────────┐┌────────┐┌────────┐                                     │
│ │概览简报 ││资金流向 ││宏观日历 │                    08/19 07:40 · HKT ▾  │
│ └────────┘└────────┘└────────┘                                     │
├────────────────────────────────────────────────────────────────────┤
│                        内容区(最大宽度 1600px 居中)                 │
└────────────────────────────────────────────────────────────────────┘
```

框架规则:

- 顶部标题栏:左为面板名(建议由"数据中心与宏观"更名为"市场脉搏",弱化"数据中心"的机房歧义),右为三城时钟(纽约/香港/东京)+ 本地时间与 HKT 时区切换。
- 一级导航为**三个**平级 tab,无二级嵌套;tab 切换保持各页状态(滚动位置、筛选)。个股微观内容不在此面板——已整体并入行情页"个股工作台"(见文末说明)。
- 内容区采用 12 列栅格,卡片间距 12px(紧凑密度)/ 16px(标准密度),页面左右留白 24px。
- 密度与场景联动:监控场景用紧凑密度、研究场景用标准密度。

三 tab 分工一览:

| Tab | 回答的问题 | 场景 |
|---|---|---|
| ① 概览简报(默认落地) | 昨夜发生了什么?今天盯什么? | 盘前 |
| ② 资金流向 | 钱在往哪里流? | 盘中 |
| ③ 宏观日历 | 宏观节奏如何?接下来有什么事件? | 盘后 / 研究 |

个股维度由顶级页面"个股工作台"(行情与高频盘口重构后)承接:自选池 + K 线 + 右栏 [盘口|微观] 切换。详见《行情页重构方案 · 个股工作台》。

分区说明:

- A 区 · 全球市场脉搏:跨市场报价的唯一入口。类目条为筛选 chips,支持"类目自定义"(勾选隐藏不看的类目,偏好持久化)。每张资产卡固定结构:代码、中文名、大数值、涨跌徽章、迷你走势线、数据日期与来源点。休市资产显示昨收价 + "休市"灰标签,绝不显示 0.00。
- B 区 · 情绪与风险:等宽三卡。左卡为贪婪恐惧渐变条(红→绿)配游标与读数,下方挂 VIX 次级指标;中卡为 7 轴风险雷达,右上角放"指标说明 / 算法"两个解释入口;右卡为 PCR 期权情绪(顶级期权波动率页撤销后迁入)——当前 PCR 读数 + 偏多/偏空状态(>1 偏空 / <1 偏多)+ 60 日 PCR 与 VIX 双轴迷你图。三卡左下统一数据源角标、右下更新时间。这是全面板差异化内容,固定首屏。
- C 区 · 今日焦点:三张等宽摘要卡——今日高影响经济事件(最多 3 条)、本周财报(最多 3 个标的)、资金一句话(最大流入 + 最大流出各一条)。每卡右下角"查看全量 →"跳转对应 tab。只摘录、不新增数据。

### 五、原"个股深度"→ 已迁出至个股工作台

本设计稿早期版本含第四个 tab"个股深度"(标的条 + 批量快照 + 主力筹码 + L2 盘口 + 卖方共识 + 卖空拥挤度)。定稿决定:**整体迁出本面板,并入顶级页面"个股工作台"**(行情与高频盘口重构),理由与落位如下:

- 主题同源:个股微观结构与行情页的自选池/K 线/L2 盘口本就围绕同一标的,拆开反而要求用户跨页看一只票。
- 去重不迁:L2 盘口深度(与行情页 PixiJS 档位盘口重复)、批量实时快照(与自选池重复)两块直接废弃;真正迁入行情页右栏"微观"tab 的只有主力筹码分层、卖方共识 vs 基本面、卖空拥挤度(仅港股)+ 折叠的基础信息。
- 原"标的条"与行情页自选池合并为同一份持久化自选 store,不再有两套自选。
- 本面板由此瘦身为纯宏观 3 tab,页内不再出现任何单标的微观数据与硬编码 ticker。

交互衔接:概览①资产卡、资金流向②板块行的点击跳转目标由"个股深度 tab"改为 `/market/:ticker` → 个股工作台。详见《行情页重构方案 · 个股工作台》。

### 七、通用视觉规范

色彩语义(全局唯一标准):

| 用途 | 颜色 |
|---|---|
| 涨 / 流入 / 利好 | emerald-400 |
| 跌 / 流出 / 利空 | red-400 |
| 警示 / STALE / 频率提示 | amber-500 |
| AI 生成内容 | 紫色徽章 |
| 中性 / 持平 / 休市 | gray-500 |
| 背景 / 卡片 | #0F0F14 / gray-900 + 细描边 |

字体层级:核心数值 24~28px 粗体;次级数值 14px;标签与说明 12px gray-400;金额千分位,单位紧跟(亿/亿美元)。

状态先于数字——三条硬性规则:

1. 休市与缺数据显示昨收或"—",配灰色状态标签;任何情况下不出现 0.00 假值与无方向的 "+0.00%" 绿色徽章。
2. 过期/断连数据:数值区 opacity-60 + saturate-50,并挂琥珀色 STALE 标签;大面积过期时页面顶部出全局提示条。
3. 空态:无数据的子页/区块用空态插画 + 一句说明 + 预计更新时间,不渲染 "--" 占位符。

元信息规范:

- 每个区块左下固定"数据源"角标,右下固定"更新时间";存量数据额外标注更新频率徽章(实时 / 日更 / 半月报)。
- AI 生成内容(前瞻推演、情感打分)一律带"AI 生成 · 仅供参考"徽章。
- 三城时钟与时区切换只在面板头部出现一次,不在各页重复。
