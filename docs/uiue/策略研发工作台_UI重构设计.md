## 策略研发工作台(Strategy Dev)· UI/UE 重构设计

> 目标:把"写策略 → 验证 → 部署"的动线理顺:动作入口去假存真、模式切换从隐藏快捷键变成可见 tab、错误从状态栏红字升级为诊断卡、AI 落码语义统一为"必过 Diff 确认"。
> 范围:纯 UI/UE 设计,不改代码;设计 tokens 与既有导入稿一致(bg #0F0F14 / panel #16181F / up #34D399 / down #F87171 / warn #FBBF24 / ai #A78BFA / blue #60A5FA)。
> 配套 Figma 稿:《策略研发工作台_Figma导入稿.html》(3 帧:代码模式 / 回测报告模式 / AI 协作与状态规范)。
> 日期:2026-08-20 · 代码落点已核对 `features/strategy/`(见文末事实索引)

### 一、现状诊断(截图 + 代码核对)

1. **动作按钮一真一假。** Topbar 的"运行沙箱 / 部署至 OMS"是**空壳**,只弹 toast(`layout/topbar.tsx:21-31`);真正的按钮藏在右栏动态参数区。同一动作两处入口,其中一处是假的——最伤信任的 UE 问题。
2. **模式切换是隐藏快捷键。** M1 代码 / M2 回测 / M3 AI 助手实为 ⌘1/⌘2/⌘3 + 底部一行小字(`strategy-ide.tsx:31-49`);新用户根本不知道有回测视图。更糟:⌘2 dispatch 的 `quant_focus_backtest` 事件**全仓无监听者**,是个死快捷键。
3. **错误挤在状态栏。** "架构规范缺失:未检测到继承自 BaseStrategy 的策略类…"以内联红字与"保存/语法检查"按钮挤在同一行;行号信息埋在文案里,没有点击跳转。
4. **AI 落码语义自相矛盾。** 面板文案写"AI 生成的代码将自动应用到左侧主编辑器中",实际走 Diff 双栏审查(`diff-overlay.tsx`);但**编辑器为空时跳过 Diff 直接覆盖**(`ai.slice.ts:76-80`)——文案、主流程、例外三者各说各话。
5. **草稿库冷启动差。** 新建草稿只有 `# Draft Strategy...`,无模板;所有草稿状态被后端硬编码为 `testing` 并显示"测试"徽章(`routers/strategy.py:447-451`),徽章没有信息量。
6. **回测两个入口。** 工作台内置完整回测报告(Tear Sheet + 净值/回撤/交易流水五 tab),同时顶级还有"高频回测引擎"页走另一套端点(`/backtest/run/stream` vs `/strategy/run-sandbox/stream`)——与 Fund Flow 同型的碎片化。
7. **部署无闸门可见。** 动态参数表单的"部署实盘"按钮在 UI 上不体现 SANDBOX/LIVE 语义与 `REAL_TRADE_EXECUTE` 校验(宪法 §4 要求 UI 显示 SANDBOX/LIVE 横幅)。
8. **装饰性假状态。** 终端前两行"QuantEdge Strategy IDE Initialized / Agent Connection: OK"为硬编码装饰文案(`bottom-terminal.tsx:83-84`),违反"状态先于数字、禁止假状态"。
9. 工程债(不在本设计范围,列此备查):孤儿 store `useStrategyStore.ts`(184 行,含写死 US.AAPL);两处几乎相同的正则字符串参数注入;`window.prompt()` 做预设命名;多个文件超编码宪法行数顶。

### 二、重构后功能分区

三列骨架保留(现有 ResizablePanelGroup 不动),重排职责:

```
┌────────────────────────────────────────────────────────────────┐
│ Topbar:草稿名 + 已同步 · [SANDBOX]          [版本][草稿库]       │
├──────────┬───────────────────────────────────┬─────────────────┤
│ A 草稿与  │ 模式 tabs: [代码] [回测报告]        │ D AI 副驾        │
│   模板    │ ┌ B 编辑器(Monaco)────────────┐   │ ① Copilot 对话   │
│ 草稿列表   │ │ class RsiReversal(Base…)     │   │ ② 动态参数表单    │
│ (真实状态) │ │ …squiggle 行级标注…          │   │ ③ 沙箱环境        │
│ ──────── │ └────────────────────────────┘   │ ────────        │
│ 模板中心   │ C 诊断区:错误卡(行号跳转+AI修复)   │ [运行沙箱] 主按钮   │
│ RSI双均线 │ ─────────────────────────────    │ [部署至 OMS…]     │
│ 网格/突破  │ 日志抽屉(可折叠,级别分色)          │ Diff 确认在此发起   │
└──────────┴───────────────────────────────────┴─────────────────┘
```

**A 区 · 草稿与模板(左列)**
- 草稿列表状态徽章改为真实状态:草稿 / 已回测 / 已部署(来源 = 最近一次动作记录),删除全局写死的"测试"。
- 列表下方新增**模板中心**折叠区:空白 / RSI 双均线 / 网格 / 突破跟随,每个模板带一句话说明;新建草稿从模板生成(含标准 BaseStrategy 骨架),直接消灭"架构规范缺失"这类冷启动报错。
- 收藏、重命名、删除保留现状交互。

**B 区 · 编辑器与诊断(中列 · 代码模式)**
- Monaco 保留;行级 squiggle 保留。
- 状态栏只留状态(已同步/未保存 + 格式化),**红字诊断全部迁出**到编辑器下方"诊断区":每条错误一张卡(错误码 + 说明 + `第 N 行 → 点击跳转` + [AI 修复] + [忽略一次]),错误卡规范同选股页。
- "强制语法检查"改为诊断区右上角的"重新检查"。

**C 区 · 日志抽屉(中列底部)**
- 沙箱运行日志(HTTP NDJSON 流)收纳为**可折叠抽屉**:折叠态一行显示"运行中 · 12 步 · 最新:下单回测撮合完成",展开后级别分色(INFO 灰 / WARNING 琥珀 / ERROR 红,对齐宪法日志语义)。
- 删除硬编码装饰开场白;首行即真实事件。运行失败时抽屉头部挂错误卡 + 重试。

**D 区 · AI 副驾(右列)**
- 自上而下三段:Copilot 对话 → 动态参数表单 → 沙箱环境表单(现状组件均在,只重排)。
- **动作按钮收编到右列底部**:删除 Topbar 空壳按钮;"运行沙箱"为主按钮(蓝),"部署至 OMS…"为次按钮(打开确认流程,见 Frame 3)。
- AI 落码语义统一:**永远走 Diff 确认**,删除空编辑器直写例外;面板底部文案改为"生成代码需经 Diff 审查后应用"。Diff 卡双栏对照 + [应用][拒绝],应用即进入版本历史。

**模式 tabs(中列顶部)**
- 把 ⌘1/⌘2 的隐藏模式升为可见 tabs:`[代码][回测报告]`;⌘3 聚焦右栏对话(保留快捷键,作为辅助而非唯一入口)。修复 ⌘2 死事件(tabs 即监听者)。
- 回测报告模式 = 现有 `backtest-report.tsx` 内容升为整区:指标条 + 五 tab(净值/回撤/收益分布/交易流水/限价挂单)+ 寻优 Top3;参数"应用"统一走 Diff。

### 三、与"高频回测引擎"的分工(碎片化处置)

- 工作台回测 = **单策略沙箱推演**:参数寻优、蒙特卡洛、Walk-Forward,端点族 `/strategy/run-sandbox/*`。
- 顶级"高频回测引擎" = **独立大规模回测**:自有配置与结果组件,端点 `/backtest/run/stream`。
- 本期**不合并**(端点、组件均独立,合并成本高),但必须:两页互加"在…打开"跳转链接;工作台回测报告头部标注"沙箱推演口径",避免与引擎结果混淆。是否最终合并列为三期决策项。

### 四、状态与闸门规范

| 场景 | 规范 |
|---|---|
| SANDBOX / LIVE | 顶栏常驻琥珀 SANDBOX 胶囊;回测报告与部署流均标注"沙箱推演,非实盘" |
| 部署至 OMS | 确认弹窗显示目标环境:SANDBOX → 仅纸面/模拟;LIVE 必须先通过 `REAL_TRADE_EXECUTE` 校验,弹窗转红 + 二次确认(宪法 §4) |
| 沙箱运行中 | 日志抽屉进度态;禁用"运行沙箱"防重复提交;中断可"停止" |
| 语法/架构错误 | 诊断卡,禁止状态栏内联红字;行号点击跳转 |
| AI 生成 | SSE/NDJSON 流式可见;失败显示错误卡 + 重试;生成的代码必过 Diff |
| 数据过期 | STALE 琥珀标签 + 区域降饱和(行情/参数快照场景) |
| 空草稿 | 编辑器空态 = 模板选择引导,不再是 `# Draft Strategy...` |

### 五、实施要点(设计层)

1. Topbar 两个空壳按钮删除,动作入口唯一化于右列底部。
2. 中列顶部加 `[代码][回测报告]` tabs,接管 ⌘1/⌘2 语义;修复/移除 `quant_focus_backtest` 死事件。
3. 诊断区组件化:错误卡 = `{code, message, line, fixable}`,Monaco markers 与诊断卡同源。
4. AI 落码删除空编辑器例外,统一 Diff;文案与行为对齐。
5. 草稿状态真实化(后端 `status` 字段接入真实状态,删除写死 `testing`)。
6. 日志抽屉:级别分色 + 折叠态摘要;删除装饰性开场白。
7. 模板中心四模板起步;新建流程 = 选模板 → 生成骨架 → 自动通过架构检查。
8. 参数应用(寻优结果/滑块)统一走 Diff 审查,替代正则字符串注入(工程侧另立工单)。
