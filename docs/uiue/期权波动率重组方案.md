## 期权波动率重组方案(设计稿,不改代码)

> 结论:**期权波动率曲面不适合单独开 tab**;其核心(个股期权)也**不进**数据中心与宏观——放进去会把刚清完的"宏观/个股混装"问题再请回来。正确归宿:个股内容进个股工作台,宏观内容回宏观面板。
> 本方案与《数据中心与宏观面板重组方案》《行情页重构方案_个股工作台》配套,三份文档定稿后统一实施。

---

### 一、现状诊断:`options-module.tsx`(90 行)= 三合一混装页

现 `/options` 顶级 tab 把三类不同受众的内容堆在一页:

| 区块 | 组件 | 受众 | 问题 |
|---|---|---|---|
| FedWatch 利率路径 | `FedWatchPanel`(130 行) | **宏观** | 与期权无关,误入期权页;应归宏观日历 |
| 损益实验室 | `OptionStrategyLabPanel`(149 行) | **个股** | `ticker="US.AAPL"` 写死 |
| 单合约 Greeks | `OptionVolatilityPanel`(101 行) | **个股** | 写死 OCC 合约 `US.AAPL260320C200000`——截图中"未知股票"红字报错的直接根源 |
| IV 热力图 / 3D 曲面 | `OptionVolSurface`(222 行)/ `OptionVolSurface3D`(255 行) | **个股** | 顶部标的输入框只驱动这两块,与损益实验室/Greeks 不同步——选择器只接了一半 |
| PCR 情绪 | `OptionPcrPanel`(160 行) | **宏观** | 全市场指标,误入期权页;且用**裸 fetch** 调 `/macro/sentiment-history`,违反 `@/lib/api-client` 规范 |

其他问题:

- 错误呈现为面板内红色小字(如"未知股票"),无重试入口,违反 EmptyState/状态先于数字规范。
- `options-screener-panel.tsx`(435 行)为**孤儿文件**,全仓无 import,属死代码。
- 标的输入框为自由文本,不与任何自选池联动;切换标的后三个写死组件纹丝不动,页面语义分裂。

一句话:这一页里**宏观的该回宏观,个股的该跟自选走,剩下的壳删掉**。

### 三、个股工作台 · 期权模式设计

位置:行情页(个股工作台)中列顶部,与 K 线平级的模式切换。

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 个股工作台     左:自选池      │  中列: [K线][期权] ← 新增模式切换    │ 右:[盘口|微观] │
├──────────────────────────────┼──────────────────────────────────────┼──────────────┤
│ ▸ MU.US  108.42  +1.12% ●选中 │ ┌ 期权摘要条 ────────────────────────┐ │ (不受影响)   │
│ ▸ HK.00700 442.2  +0.85%      │ │ ATM IV 38.2% · IV分位 64% ·        │ │              │
│ ▸ US.AAPL 231.5  -0.32%       │ │ 30日已实现波动 31.5% · Skew +2.1   │ │              │
│ …                             │ └────────────────────────────────────┘ │              │
│                               │ [IV 热力图] [3D 曲面]  视图切换          │              │
│                               │ ┌ 热力图: 行=行权价 列=到期日 ────────┐ │              │
│                               │ │ ATM 行高亮;单元格颜色=IV 高低      │ │              │
│                               │ │ 点击单元格 → 选中合约(蓝框)        │ │              │
│                               │ └────────────────────────────────────┘ │              │
│                               │ ┌─ 损益实验室 ───┐ ┌─ Greeks(选中合约)─┐│              │
│                               │ │ 策略选择 +     │ │ MU.US 261017 C110 ││              │
│                               │ │ payoff 图      │ │ Δ0.58 Γ0.032      ││              │
│                               │ │ (ECharts)      │ │ Θ-0.11 ν0.21      ││              │
│                               │ └────────────────┘ │ IV 38.2%          ││              │
│                               │                    └───────────────────┘│              │
└──────────────────────────────────────────────────────────────────────────┘
```

交互规则:

- 标的来源 = 左列自选池当前选中标的(与 K 线、盘口、微观同源),彻底删除自由文本输入框;自选池切换时期权区整体联动刷新。
- 期权摘要条为自选标的的"一眼概览":ATM IV、IV 分位、30 日已实现波动、Skew;无期权链数据的市场(如部分港股)显示空态"该标的无场内期权链"。
- 热力图/3D 曲面共用 `[IV热力图][3D曲面]` 分段视图切换;热力图 ATM 行高亮,单元格颜色映射 IV 高低(沿用 emerald→amber→red 语义)。
- **单元格点击选合约**:点击热力图任一单元格 → 该合约进入选中态(蓝框描边)→ 下方 Greeks 卡与损益实验室默认行权价联动刷新。这一步替代写死的 OCC 合约,是本次改造的关键交互。
- 损益实验室保留策略下拉(跨式/勒式/价差等),payoff 图用 ECharts(分析图规范)。
- 错误处理统一走 EmptyState 式错误卡 + 重试按钮,禁止内联红字;无数据/接口失败不渲染 "--"。
- 模式状态持久化:记住每标的上次停留在 K 线还是期权(Zustand persist)。

端点映射(全部复用现有):

| 区块 | 端点 |
|---|---|
| 摘要条 / 热力图 / 3D | `GET /options/chain-matrix/{symbol}?max_expiries=8&max_strikes=21` |
| 损益实验室 | `GET /market/option-strategy-lab` |
| Greeks | `GET /market/option-volatility` |

### 四、宏观面板承接

**① 概览 B 区:双卡 → 三卡**

```
├──────────────────────┬──────────────────────┬──────────────────────┤
│ 市场情绪风向标          │ 宏观风险雷达            │ PCR 期权情绪           │
│ 贪婪恐惧 55.8 + VIX   │ 7 轴雷达 + 说明/算法    │ PCR 0.87 · 偏多        │
│                      │                      │ 60日 PCR+VIX 双轴小图  │
└──────────────────────┴──────────────────────┴──────────────────────┘
```

- PCR 卡内容:当前 PCR 读数 + 状态解读(>1 偏空 / <1 偏多,阈值可配)+ 60 日 PCR 与 VIX 双轴迷你图(ECharts)。
- 左下数据源角标、右下更新时间,同 B 区其余两卡;AI 无关,不加 AI 徽章。
- 端点 `/macro/sentiment-history?limit=60` 复用,但调用改走 `@/lib/api-client`(顺手修掉裸 fetch 违规)。

**③ 宏观日历:子页签 7 → 8,新增「利率路径」**

```
子页签: [经济日历][财报][分红][新股][交易时段][利率路径][FRED图表][快讯情感]
```

- 利率路径页内容:FedWatch 阶梯折线(各 FOMC 会议的隐含利率路径)+ 下次会议加息/降息概率摘要 + 会议日期倒计时徽章。
- 数据口径标注:**"隐含利率来自联邦基金期货定价(Futu FedWatch),非 FOMC 点阵图"**——避免与 FRED 的点阵图/预测数据混淆。
- 组件 `FedWatchPanel` 端点 `GET /macro/fed-watch` 不变,仅搬家 + 去掉页面级包裹壳。
