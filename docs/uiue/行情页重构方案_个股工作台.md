## 行情页重构方案 · 个股工作台(Stock Workbench)

> 目标:把"行情与高频盘口"升级为**个股工作台**——个股实时行情与微观结构的唯一入口。
> 关键决策:数据中心与宏观设计稿中的"个股深度"tab 整体并入本页;数据中心与宏观瘦身为纯宏观 3 tab。
> 交互定案:微观面板落位于**右栏 tab 切换 [盘口 | 微观]**(保留现有三列骨架,改动最小、窄屏友好)。
> 追加定案(期权重组):顶级"期权波动率曲面"tab 撤销,个股期权内容(IV 热力图/3D 曲面/损益实验室/Greeks)落位于**中列模式切换 [K线 | 期权]**,详见《期权波动率重组方案》。
> 范围:纯 UI 布局与功能规划,不改代码。代码落点基于 quant_agent 仓库现状(已核对文件)。
> 日期:2026-08-19

---

### 一、为什么个股深度应该搬进来

1. **主题同源。** 行情页(`features/trading/quotes.tsx`)的一切——自选池、K 线、L2 盘口——都围绕"选中标的"展开;个股深度的主力筹码、卖方共识、卖空拥挤度正是同一标的的微观结构。一个看个股的页面,理应能看全这只股票。
2. **宏观面板解绑。** 搬走后,数据中心与宏观只剩 概览简报 / 资金流向 / 宏观日历 三个纯宏观 tab,兑现"宏观不出个股"原则,彻底移除该面板里的硬编码 ticker。
3. **两处重复被天然消掉(不搬,直接去重):**
   - 个股深度的 `OrderBookPanel`(L2 盘口深度)与行情页已有的 PixiJS `order-book-webgl.tsx`(零 GC 对象池、5/10/20/40 档、大单提示)功能重复——保留 PixiJS 版,弃用前者。
   - `MarketSnapshotPanel`(批量实时快照)与行情页自选池重复——自选池本就逐条显示价格/涨跌幅,就是批量快照,不再单独存在。
4. **联动通道已现成。** `/market/:ticker` 路由重定向(sessionStorage `quant_target_symbol`)已存在:宏观面板点击任意标的 → 直达本页并选中,无需新建机制。

真正迁移的只有三个自取数 widget(均已在 `features/data-center/` 确认存在,ticker 参数化):主力筹码分层(`capital-distribution-panel.tsx`)、卖方共识 vs 基本面(`analyst-vs-fundamental-panel.tsx`)、卖空拥挤度(`short-selling-panel.tsx`,仅港股标的显示)。

### 二、现状诊断(基于截图与代码)

1. **右栏单一。** 右栏只有 L2 DOM,休市时整列是 `---` 占位行,页面信息密度骤降;微观结构内容在仓库另一头,看一只票要跨两个顶级页面。
2. **硬编码兜底。** `quotes.tsx` L84 `selectedSymbol = '00700.HK'` 写死;自选池为空时仍渲染腾讯行情,违反"空态必须可见"。截图里 `0700.HK / AAPL / 00772.HK` 的 0.00 +0.00% 灰行正是兜底数据的痕迹(生产应走空态/昨收规范)。
3. **体量超限。** `quotes.tsx` 310 行,已超编码宪法 feature 页 250 行硬顶;本次重构顺手拆分。
4. **休市态无说明。** 盘口空行应标注"休市 / 等待开盘"而不是裸占位(代码里已有 `closedText` 机制,需保留并前置)。

### 三、重构后布局

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 个股工作台 · STOCK WORKBENCH    [MU.US  442.20  +0.85%]  状态: 休市/开盘中 │

│ │AAPL    │ │ └───────────────────────────────────┘  │ │ 成交流水        │ │

│            │                                         │ │ 卖方共识vs基本面│ │
│            │                                         │ │ 卖空拥挤度(港股)│ │
│            │                                         │ │ ▸ 基础信息(折叠)│ │
│            │                                         │ └────────────────┘ │
└────────────┴─────────────────────────────────────────┴───────────────────┘
列宽:react-resizable-panels 保留,左 ~20% / 中 ~55% / 右 ~25%(现状 20/60/20 微调)
```

要点:

- **骨架不动。** 继续用 `react-resizable-panels` 三列(左自选池 / 中 K 线 / 右栏),移动端继续走 vertical 堆叠;≥2560px 的 ultrawide AIChat 第四列不受影响。
- **中列顶部新增 `[K线][期权]` 模式切换**(shadcn Tabs)。K 线模式 = 现状零改动;期权模式 = 顶级期权波动率页撤销后迁入的个股期权内容(摘要条 + IV 热力图/3D 曲面 + 损益实验室 + Greeks),详见第四节。模式选择随标的持久化。
- **右栏是本方案的核心改动。** 顶部加 `[盘口][微观]` 分段切换(shadcn Tabs,复用移动端已有的 DOM/成交流水切换模式):
  - 盘口 tab = 现状整体保留(PixiJS 档位盘口 + 大单提示 + 成交流水)。
  - 微观 tab = 三个迁入 widget 纵向堆叠,全部以**自选池选中标的**为参数;卖空拥挤度仅港股标的渲染,其余市场自动隐藏;底部挂默认折叠的"基础信息"。
  - 切换记忆:选择持久化(localStorage),盘中默认落 盘口、研究场景默认落 微观。
- **自选池 = 全页唯一选择器。** 点击行 → K 线与右栏同时切换标的;`selectedSymbol` 的写死兜底删除,自选为空时中/右栏显示空态引导("添加第一个标的开始看盘"),不再渲染 0.00 假值。
- **K 线区零改动。** 分时/Tick/5日/日K/周K/月K、指标开关(MA20/MA50/MA200/BB/MACD/RSI/KDJ)、键盘快捷键 1-6、对比模式全部保留。
- **状态先于数字。** 休市时盘口保留"休市"说明文案(不裸 `---`);右栏数据过期走 STALE 琥珀标签 + opacity-60;微观 tab 各卡带数据源角标与更新频率徽章(筹码/共识日更,卖空港股日更)。

### 四、中列 · 期权模式(期权波动率页撤销后迁入)

背景:顶级"期权波动率曲面"tab 判定撤销(宏观内容误入 + 个股内容写死标的),个股期权四件套迁入本页面中列,完整论证见《期权波动率重组方案》。此处只定布局落点:

```
中列 [期权] 模式自上而下:
┌ 期权摘要条 ─────────────────────────────────────────────┐
│ ATM IV 38.2% · IV 分位 64% · 30日已实现波动 31.5% · Skew +2.1 │
├─────────────────────────────────────────────────────────┤
│ [IV 热力图] [3D 曲面] 视图切换                             │
│ 热力图:行=行权价 / 列=到期日,ATM 行高亮,颜色=IV 高低;      │
│ 点击单元格 → 选中合约(蓝框)→ 下方 Greeks 联动             │
├──────────────────────────┬──────────────────────────────┤
│ 损益实验室(策略下拉+payoff)│ Greeks(选中合约)             │
│ ECharts,标的随自选池       │ Δ/Γ/Θ/ν/IV + 合约号          │
└──────────────────────────┴──────────────────────────────┘
```

规则:

- 标的来源 = 自选池当前选中(与 K 线、盘口、微观同源);删除原页面的自由文本标的框与一切写死 ticker/OCC 合约。
- 无期权链的标的(部分港股等)显示空态"该标的无场内期权链",不渲染 "--"。
- 错误一律走 EmptyState 式错误卡 + 重试,禁止内联红字。
- 端点全部复用现有:`/options/chain-matrix/{symbol}`、`/market/option-strategy-lab`、`/market/option-volatility`,后端零改动。
- 原 `options-module.tsx` 壳与 `options-screener-panel.tsx`(435 行孤儿)删除;`/options` 路由重定向至本页。

### 五、与宏观面板的分工与联动

| 面板 | 回答的问题 | tab/页 |
|---|---|---|
| 数据中心与宏观(市场脉搏) | 市场整体怎么样? | ①概览简报 ②资金流向 ③宏观日历(3 tab) |
| 个股工作台(行情) | 这只票现在怎么样? | 自选池 + 中列 [K线\|期权] + 右栏 [盘口\|微观] |

联动路径(双向):

1. 宏观 → 个股:概览资产卡 / 板块排行行点击 → `/market/:ticker` → 本页自动加入自选并选中(机制已存在,只需接上点击入口)。
2. 个股 → 宏观:微观 tab 的"所属板块"标签点击 → 资金流向页对应市场视图(二期)。
3. 自选池与个股深度原"标的条"合二为一:同一份 Zustand 持久化 store(`quant-watchlist-storage`),宏观面板的自选 chips 不再单独建第二套。
4. 期权页的宏观内容不归本页:FedWatch → 宏观日历「利率路径」子页签,PCR → 概览 B 区第三卡(见《期权波动率重组方案》)。
