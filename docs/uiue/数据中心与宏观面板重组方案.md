## 「数据中心与宏观」面板重组方案

> 目标:把臃肿的数据堆叠改造成适合个人投研的分层看板。
> 设计输入:三场景兼顾(盘前简报 / 盘中监控 / 盘后研究)、宏观与个股均衡。
> 范围:纯前端信息架构重组,不改动任何数据源与后端接口。
> 配套文档:《行情页重构方案 · 个股工作台》《期权波动率重组方案》《数据中心与宏观 · UI 设计与功能布局》。
> 日期:2026-08-19 · 代码落点基于 quant_agent 仓库现状

---

### 一、现状诊断:为什么现在不好用

概览 tab 目前把 **16 个区块**按开发顺序平铺在一个页面里(`features/trading/data-center.tsx` L329–399),问题集中在四点:

1. **按数据类型堆放,而不是按任务组织。** 用户打开看板是要完成三件事——"昨夜发生了什么、钱在往哪流、我关注的股票微观结构如何",但现在的页面回答不了任何一个,只能从头读到尾。
2. **宏观与个股互相污染。** L2 盘口、主力筹码、卖方共识这些单标的微观面板和 FRED、经济日历混在同一屏,且标的写死为 HK.00700 / US.AAPL,无法换成自己关注的票。
3. **同一内容出现两次。** 经济日历、财报前瞻在概览和"市场日历"tab 各有一份;大类资产走势(18 卡片)与日历 tab 的 Markets 视图功能重叠。
4. **首屏没有焦点。** 情绪风向标、风险雷达是全面板最有辨识度的内容,却被压在页面中下部。
5. **跨页面碎片化。** 侧边栏顶级 Fund Flow(北向/南向资金实时看板)tab 与数据中心构成资金的第二个入口:南向净流入、行业分布、美股板块 ETF 都与数据中心重叠,而 日/周/月 周期、双通道拆解、ETF 贡献分解这些独特能力却散落在外。
6. **期权页三合一混装。** 顶级"期权波动率曲面"tab(`options-module.tsx`,90 行)把宏观内容(FedWatch 利率路径、PCR 期权情绪)与个股内容(IV 热力图/3D 曲面/损益实验室/Greeks)堆在一页:个股部分标的写死(US.AAPL、OCC 合约 `US.AAPL260320C200000`,即截图中"未知股票"报错的根源),标的输入框只驱动热力图/3D 两块;PCR 还用裸 fetch 绕过 api-client。这是继 Fund Flow 之后的第三个跨页面碎片化点。

另有代码层面的佐证:`data-center.tsx` 已 403 行,超出仓库编码宪法的 feature 页 250 行硬顶;`short-interest.tsx`、`asset-trend-cards.tsx`、`options-screener-panel.tsx`(435 行)是无人引用的孤儿文件。

### 二、设计原则

1. **按任务分页,一页一问。** 每个 tab 回答一个问题,首屏给出该问题的直接答案。
2. **宏观不出个股,个股页标的可配。** 宏观/资金页禁止出现单标的微观数据;个股页所有面板由自选标的驱动,彻底移除硬编码 ticker。
3. **摘要 + 全量,最多两处。** 概览只放摘要卡,全量内容在对应专题 tab,双向跳转,消灭内容复制。
4. **状态先于数字。** 休市/更新频率/STALE 标注的视觉优先级高于数值本身(沿用仓库 EmptyState / DataSourceBadge / STALE 琥珀标签规范)。

### 三、新信息架构:四个 tab

```
数据中心与宏观(建议更名:市场脉搏 · Market Pulse)
├─ ① 概览简报(默认落地)→ 昨夜发生了什么?今天盯什么?
├─ ② 资金流向            → 钱在往哪里流?
└─ ③ 宏观日历            → 宏观节奏如何?接下来有什么事件?
```

个股维度不在本面板:早期方案的"④ 个股深度"定稿**整体迁出**,并入行情页重构后的**个股工作台**(自选池 + K 线 + 右栏 [盘口|微观]),详见《行情页重构方案 · 个股工作台》。

同时撤销侧边栏顶级 **Fund Flow(北向/南向资金)** tab:约七成内容与数据中心重叠,三项独特能力(日/周/月 周期、南向双通道下钻、美股板块 ETF 贡献分解)迁入资金流向②,环形图与"北向净买入"不迁移(见第五节)。资金从此只有一个入口。

同时撤销侧边栏顶级 **期权波动率曲面** tab(三合一混装,见诊断第 6 点):宏观两块回本面板——FedWatch 利率路径 → 宏观日历③新子页签「利率路径」,PCR 期权情绪 → 概览① B 区第三卡;个股期权四件套 → 个股工作台中列 `[K线|期权]` 期权模式。详见《期权波动率重组方案》。

场景映射:盘前 → ①;盘中 → ②(个股微观去个股工作台);盘后/研究 → ③。宏观与个股之间由 `/market/:ticker` 跳转桥接(见第六节)。

要点:
- "全球市场脉搏"合并现有**大类资产走势**(概览内联 tile)与日历模块 **MarketsView** 的类目侧边栏,成为唯一的跨市场报价视图,消除两处重复。类目侧边栏复用现有 `quant_calendars_hidden` 隐藏机制。
- 情绪 + 雷达 + PCR 升为首屏第二排等宽三卡(现布局 `lg:grid-cols-[220px_240px]` 扩为三列);PCR 卡自撤销的期权页迁入,端点 `/macro/sentiment-history` 复用,裸 fetch 改走 api-client。
- "今日焦点"不新增数据源,纯摘录 `/macro/dashboard` 已返回的 economicEvents / earningsCalendar / capital-flow 数据。

要点:

#### ③ 宏观日历——盘后研究与事件追踪

```
子 tab 条(复用 calendars 模块 TABS 配置模式,标签统一中文):
```

要点:
- 即现有 `CalendarsModule` 的 6 个子 tab,加上从概览迁来的 FRED 与 LLM 快讯,再加上从撤销期权页迁入的 FedWatch「利率路径」,共 8 个。
- 利率路径页标注数据口径:"隐含利率来自联邦基金期货定价(Futu FedWatch),非 FOMC 点阵图"。
- 概览里的"主脑前瞻推演"(AI 解读)随经济日历迁到这里,并加"AI 生成,仅供参考"标注。
- MarketsView 已并入概览①,从本 tab 移除。

#### ④ 个股深度 —— 迁出本面板(定稿变更)

早期方案在本面板设第四个 tab 承载个股微观面板。定稿:整体迁出,并入行情页"个股工作台"右栏微观 tab——个股微观与行情页的自选池/K 线/L2 盘口本就围绕同一标的;L2 盘口、批量快照两处与行情页重复,直接去重不迁。本面板从此无任何单标的微观数据与硬编码 ticker。落位细节见《行情页重构方案 · 个股工作台》。

### 六、横向交互(均衡风格的关键)

1. **标的跳转路径:** 概览①资产卡点击 → `/market/:ticker` → 个股工作台(自动加入自选并选中);板块条目点击 → 资金流向②对应市场。这是宏观与个股之间的桥,替代"把所有东西堆一页"。
2. **场景模式联动:** 仓库已有 `SCENE_MODES`(watch/research/monitor/ai-analysis)。建议 monitor 场景默认落地资金流向②,research 落地宏观日历③,watch 落地概览①——复用现有密度预设,零新增机制。
3. **时段感知默认页(可选增强):** 盘前(<09:00 HKT)默认概览①,美股盘中时段默认资金流向②。
4. **空态与状态:** 无数据的子页(如港股板块资金流)用 EmptyState + 说明文案,不渲染占位 "--";所有面板保留数据源角标与更新时间。
