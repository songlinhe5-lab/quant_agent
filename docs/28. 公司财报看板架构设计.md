## 一、目标与对标

### 1.1 要解决的问题

现状：仓库已有**零散的**基本面能力，但没有「公司财报」这个第一公民。

| 缺口 | 现状证据 | 业界方案 | 本模块交付 |
|:---|:---|:---|:---|
| 无一手申报源 | 全部数据来自二手聚合商（Futu / FMP / YF / Tushare） | SEC EDGAR 官方 XBRL | 三地一手源：EDGAR / 披露易 / 巨潮 |
| `get_fundamental` 是假基本面 | Futu `FUNDAMENTAL` 只返回 PE/PB/EPS 快照 5 字段 | 完整三表 + 附注 | 归一化事实层，科目级可查 |
| 无历史深度 | 各源接口只给最近若干期，且口径互斥 | 10~20 年标准化历史 | 事实表按期存全量，一次回填 |
| 无重述追踪 | 拿到什么算什么，改了不知道 | as-reported vs restated 双轨 | 双时间轴，重述自动 diff 告警 |
| 无同业/行业对比 | 只有单票视图 | 同业中位数 + 截面分位 | peer set + EDGAR `frames` 截面 |
| 财报只能问不能算 | `earnings-qa-panel` 仅 RAG 问答 | 结构化指标 + 文本双通道 | 数字走事实层，文本走 RAG |

### 1.2 「一手」的定义与三地口径

一手 = **发行人向法定披露平台提交的原始申报**，而非数据商加工结果。三地成熟度差异极大，必须分层对待，不能假装统一：

| 市场 | 一手源 | 结构化程度 | 数字层落法 | 文本层落法 |
|:---|:---|:---|:---|:---|
| 美股 | SEC EDGAR（`data.sec.gov`，免费无 Key） | **XBRL 全量事实**，逐 tag 带 `filed`/`accn`/`start`/`end` | 直接进事实表（权威） | 10-K/10-Q 原文进 RAG |
| 港股 | HKEXnews 披露易 | **仅 PDF**，无 iXBRL 公开接口 | 数字层退回 Futu `FINANCIALS`（已有） | PDF 进 RAG + LLM 抽取（须带页码） |
| A股 | 巨潮资讯网 CNINFO | **仅 PDF**（XBRL 未公开开放） | 数字层退回 Tushare `FINANCIALS`（已有） | 同上 |

> **诚实性红线**：港股/A股的数字层是**二手**，前端必须经 `DataSourceBadge` 标注来源与口径，禁止与 EDGAR 一手数字混在同一列不加区分（AGENTS §3）。

### 1.3 非目标（YAGNI）

- ❌ 不自建 PDF→三表 的通用解析器（港股/A股结构化交给已有 Futu/Tushare，PDF 只做文本与定点抽取）
- ❌ 不做盈利预测模型与 DCF 估值（估值属 §二十三 优化器与策略侧）
- ❌ 不做 GICS 行业分类（商业授权），改用 SEC SIC / 申万 / Futu 板块，并在 UI 标明分类体系
- ❌ 不做实时财报推送（财报日历已在 §二十，本模块只消费）

**采集合规**（写 `filings_worker` 必看）：

- SEC 要求描述性 `User-Agent`（含联系邮箱），缺失即 403；请求频率 ≤ 10 req/s，超限会被封 IP → 归入 `data_subservice` 既有限流器，`rate_limit` 不计入熔断失败计数（AGENTS §4）。
- `companyfacts` 单公司响应可达数 MB（Apple 约 3.8MB / 500+ 概念），必须落盘缓存 + 按 `filed` 增量，禁止每次全量拉。
- 披露易 `titleSearchServlet.do` 与巨潮 `hisAnnouncement/query` 都是**页面后端接口而非开放 API**，必须 fixture 测试锁响应结构，页面改版时显式失败而不是静默拉空。
- **披露易实测契约（2026-08-31，阅文 00772 中报公告验证）**：① 必须两步——先 `prefix.do`（JSONP）解析内部 `stockId`，仅传 `stockCode` 恒查不到；② 日期参数是 `fromDate`/`toDate` 且格式 `YYYYMMDD`，传 `pubFrom`/`pubTo` 或带横杠格式会被**静默忽略**（返回全量旧数据，最危险的坑）；③ `result` 是字符串化 JSON 数组需二次 `loads`，无记录时为 `"null"` 或 `"[]"` 字符串；④ 字段全大写（`TITLE`/`DATE_TIME` 为 `DD/MM/YYYY HH:MM`/`FILE_TYPE`/`FILE_LINK`）。fixture 已按真实响应重写。
- 新增能力声明 `DS_CAPABILITIES=...,filings`；SEC 采集节点固定在美国节点，禁止从 CN-DATA 节点直连（`docs/06` 拓扑）。

## 三、事实层：归一化与双时间轴

这是本模块唯一不可外包的核心。做对了后面全是查询，做错了全是脏数。

### 3.1 声明式概念映射

标准科目 → 候选标签**有序链**，先命中先用，全部落空则该科目为 `null`（不猜、不插值）：

```json
{
  "revenue": {
    "us-gaap": ["RevenueFromContractWithCustomerExcludingAssessedTax",
                 "Revenues", "SalesRevenueNet"],
    "ifrs-full": ["Revenue"],
    "futu": ["field_id:3001"],
    "tushare": ["total_revenue"],
    "statement": "income", "sign": 1
  }
}
```

映射表**必须带版本号**并入 git；新增标签链走 PR + 单测，禁止在服务代码里补 if-else。测试方式：抽 20 家覆盖不同行业的公司做 golden case，映射改动导致任一 golden 变化即失败。

### 3.2 双时间轴（as-reported vs restated）

每条事实同时携带两条时间轴，这是防前视偏差的地基，也是重述追踪的副产品：

| 轴 | 字段 | 含义 |
|:---|:---|:---|
| 业务时间（valid time） | `period_start` / `period_end` | 会计期间本身 |
| 系统时间（knowability） | `filed_at` / `accession_no` | 该数字**何时可被市场知晓** |

去重与取值规则（EDGAR 实践，踩过的坑写死在这）：

1. 唯一键 = `(entity_id, concept, period_start, period_end, unit)`。**禁止只按 `fy` 去重**——比较期数字与本期共用同一 `fy` 标签，按 `fy` 去重会静默丢数。
2. `value_as_reported` = 该唯一键下 `filed_at` **最早**的值（首次披露，冻结不改）。
3. `value_latest` = `filed_at` **最新**的值（含修正与重述）。
4. 两者不等 → 置 `restated=true`，进重述 diff 面板。
5. PIT 查询一律 `filed_at <= as_of`，回测/因子只允许读这条通路（对齐 `financial_pit.PointInTimeStore` 现有 `announce_date` 语义，本任务把它从内存单例落到 PG）。

> **用途分工**：回测、因子、信号 → `as_reported`；「这家公司十年真实毛利率走势」→ `latest`。UI 必须让用户看得见当前在看哪一条。

### 3.3 期间推导（10-Q 的 YTD 陷阱）

10-Q 的流量科目可能是**单季**也可能是**累计**，只能靠 `(start, end)` 跨度判定，不能信 `fp` 标签：

- 跨度 ≈ 91 天 → 单季，直接用。
- 跨度 ≈ 182 / 273 天 → 累计，Q2 = H1 − Q1，Q3 = 9M − H1。
- **Q4 永远是推导值**：Q4 = FY − 9M（EDGAR 无独立 Q4 申报），推导结果必须标 `derived=true`，前端显示浅色角标。
- 存量科目（`Assets` / `StockholdersEquity`）是时点值，EDGAR `frames` 须用 `CY2024Q3I` 的 `I` 后缀，用错后缀返回 404。

### 3.4 勾稽校验（落库前门禁）

| 校验 | 断言 | 失败处理 |
|:---|:---|:---|
| 资产负债恒等 | `assets ≈ liabilities + equity`（相对误差 < 0.5%） | 标 `check_failed`，仍入库但前端标红，**禁止静默丢弃** |
| 现金流勾稽 | `cfo + cfi + cff ≈ Δcash` | 同上 |
| 毛利一致 | `revenue − cogs ≈ gross_profit`（若三者齐备） | 同上 |
| 分部加总 | 分部收入合计 ≈ 合并收入 | 仅告警（分部口径常不完备） |

## 四、Pydantic Schema 与存储

```python
class FinancialFact(BaseModel):
    """事实表最小单元。一行 = 一个科目在一个期间的一个版本。"""
    entity_id: str                    # 内部主键：US:CIK0000320193 / HK:00700 / CN:600519
    concept: str                      # 标准科目名（concept_map 的 key）
    statement: Literal["income", "balance", "cash"]
    period_start: date | None         # 时点科目为 None
    period_end: date
    fiscal_year: int
    fiscal_period: Literal["Q1", "Q2", "Q3", "Q4", "FY"]
    unit: str                         # USD / HKD / CNY / shares
    value_as_reported: float
    value_latest: float
    restated: bool = False
    derived: bool = False             # Q4 或 累计拆分的推导值
    filed_at: date
    accession_no: str | None          # EDGAR accn；港A为公告 id
    source: str                       # sec / futu / tushare
    source_tag: str                   # 原始标签，保留以便回溯映射错误
    check_failed: list[str] = []      # 勾稽失败项

class FilingRecord(BaseModel):
    entity_id: str
    form_type: str                    # 10-K / 10-Q / 8-K / 年報 / 年度报告
    fiscal_year: int
    filed_at: date
    accession_no: str
    doc_url: str
    lang: Literal["en", "zh"]
    rag_indexed: bool = False

class StatementView(BaseModel):
    """GET /financials/statements 响应：多期宽表。"""
    entity_id: str
    statement: str
    periods: list[str]                        # ["FY2021", ..., "FY2025"]
    rows: list[dict[str, Any]]                # {concept, label, values[], common_size[], yoy[]}
    basis: Literal["as_reported", "latest"]
    currency: str
    source_mix: dict[str, int]                # {"sec": 42, "futu": 0} —— 前端据此标来源
    integrity: dict[str, Any]                 # 勾稽结果摘要，不合格必须透出
```

**存储分工**：

- `financial_facts` / `filings` → **PG**（Alembic 迁移，唯一键见 §3.2；`(entity_id, concept, period_end)` 联合索引）。
- 多期宽表与截面面板 → **Parquet**（`data/snapshots/financials/`，复用 `docs/19` 目录约定），供因子与回测按 `data_snapshot_id` 读取。
- 财报原文 → 既有 `WebpageKnowledgeBase`（pgvector，`category=financial_report`），不新建向量库。

## 五、分析引擎

### 5.1 单公司

| 分析 | 输出 | 说明 |
|:---|:---|:---|
| 结构化报表 | common-size（收入/总资产为基）+ YoY/QoQ + 5/10 年 CAGR | 基础层 |
| TTM 滚动 | 四季滚动收入/利润/现金流 | 财年错位公司必须用 TTM 比 |
| DuPont 分解 | ROE = 净利率 × 周转率 × 权益乘数（可下钻五因子） | 定位 ROE 变化来源 |
| 现金流质量 | CFO/净利润、应计比率、FCF 转化率、资本开支强度 | 利润含金量 |
| 质量三分 | Piotroski F（9 项）· Altman Z · Beneish M | 均为公开可复算模型，须展示分项而非只给总分 |
| 重述追踪 | as-reported vs latest 的科目级 diff | 双时间轴的直接产物，业界少见 |

> 三个分数必须展示**分项明细与阈值**。只给一个总分而不给构成，等于让用户信一个黑箱——违反 AGENTS §5 数字可溯源。

### 5.2 同业与行业

- **peer set 解析**：SEC SIC（美股，来自 `submissions`）/ 申万行业（A股，Tushare）/ Futu 板块（港股）；三者体系不同，UI 必须标注用的是哪套。支持用户手工固定 peer 清单并保存（分析师的同业判断常优于机械分类）。
- **截面分位**：美股用 EDGAR `frames` 端点——一次请求拿到**全市场**某个 tag 在某期的取值，天然适合算行业分位，避免 N 次单票请求。
- **行业聚合**：中位数 / 四分位 / 收入加权综合值；样本 < 8 家时标注「样本不足」并禁止出分位结论（对齐 §9.7 防噪音）。

### 5.3 文本层（LLM，强制溯源）

- **MD&A / 风险因素 YoY diff**：对同一公司相邻两年年报做章节级文本相似度与差异高亮。学界依据：Cohen–Malloy–Nguyen《Lazy Prices》（JF 2020）——年报措辞的显著变化对未来收益有预测力。这是纯文本能力，投入低、区分度高。
- **定点抽取**：仅对港股/A股 PDF 做「指定科目 + 分部/指引」抽取，每个抽取值必须带 `source_page` + `source_text`；缺任一即判为抽取失败并丢弃，**不允许 LLM 给出无出处的数字**（AGENTS §5）。
- 复用既有 `routers/rag.py` 与 `earnings-qa-panel`，本模块只补「引用可跳回原文页」的定位信息。

## 六、API 端点（`routers/financials.py`，统一 `{status, message, data, timestamp}`）

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| `GET` | `/financials/statements/{entity_id}` | 多期报表（`statement` / `period` / `basis` / `limit`） |

## 九、验收标准

| 维度 | 指标 | 验收线 |
|:---|:---|:---|
| 正确性 | 20 家 golden 公司三表科目 vs 申报原文人工核对 | 逐科目一致，映射改动触发 golden 失败 |
| 正确性 | 勾稽校验 | 资产负债/现金流恒等误差 < 0.5%，超限标红不静默 |
| PIT | `as_of` 查询 | 任一历史日期查询结果不含该日之后 `filed_at` 的事实（Pytest 断言） |
| 覆盖 | 美股 XBRL 覆盖 | 目标池 10 年历史缺失期 < 5%，缺失显式列出而非补零 |
| 合规 | SEC 采集 | UA 合规 + ≤10 req/s；限流命中走退避，不计熔断 |
| 溯源 | LLM 抽取值 | 100% 带 `source_page` + `source_text`，缺失即丢弃 |
| 性能 | 单票 10 年三表 + 分析 | 缓存命中 < 1s；冷取 < 8s |
| 测试 | 后端覆盖率 | ≥ 80%（CI 门禁），单测禁打真实 SEC/Futu/外网 |

## 十、红线速查

| 禁止 | 替代 |
|:---|:---|
| 主服务直连 `data.sec.gov` / 披露易 / 巨潮 | 一律经 `data_subservice` + `DataSourceRouter` |
| 按 `fy` 去重 XBRL 事实 | 按 `(concept, start, end, unit)` 唯一键 |
| 回测/因子读 `value_latest` | 读 `value_as_reported` + `filed_at <= as_of` |
| 缺失科目补 0 或线性插值 | 置 `null`，前端显式留白 |
| LLM 给出无页码出处的数字 | 抽取失败即丢弃并报告 |
| 港A二手数字与 EDGAR 一手混列不标注 | `DataSourceBadge` 标源与口径 |
| 服务代码里写标签映射 if-else | 改 `concept_map.json` + golden 测试 |
