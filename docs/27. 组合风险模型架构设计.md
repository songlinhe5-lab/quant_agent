## 一、目标与对标

### 1.1 定位：模型层，不是展示层

现有风控（`risk_engine.py` + `routers/risk.py`）是**展示层**（雷达/集中度/敞口）；本模块是**模型层**——输出结构化协方差与风险分解，供三个下游消费：

```
                      ┌──→ §七 风控面板进阶（展示层，RISK-02~08 消费）
RiskModelService ─────┼──→ §二十三 组合优化器（协方差矩阵输入，替代样本协方差）
                      └──→ §十 告警（因子预算超支）
```

与 `RISK-02~08` 的分工：RISK 系列做面板/压测/归因展示，本模块供数值内核，不重复建设。

### 1.2 方法学选型（单兵可维护的简化路线）

| 组件 | 方法 | 理由 |
|:---|:---|:---|
| 因子集 | 市场 + 行业哑变量 + 3~5 风格（市值/动量/波动/流动性） | 无需外购因子库，可由 §二十一 因子体系自产 |
| 协方差估计 | 因子协方差 + 对角特异风险（Ledoit-Wolf 收缩可选） | 样本协方差在 N>50 时不稳定，收缩是业界标配 |
| 风险分解 | 边际/总风险贡献（MCTR/CTR） | 解析解 `w_i × (Σw)_i / σ_p`，可勾稽 |
| 观点融合 | Black-Litterman（τ 缩放 + 观点不确定性 Ω） | 把 AI/人工观点转为可优化的后验收益 |

## 二、数据流与后端模块

```
快照收益面板（SnapshotReader，日收益，最长 500 日）
        │
        ↓
FactorBuilder（市场/行业/风格因子收益序列，复用 §二十一 因子计算）
        ↓
CovEstimator（因子回归 → 因子协方差 + 特异风险；Ledoit-Wolf 可选）──→ risk_model_artifacts (PG)
        ↓
RiskDecomposer（MCTR/CTR，持仓 × 因子两级）
BlackLitterman（均衡收益 Π + 观点 Q/Ω → 后验 μ）
        ↓
routers/risk_model.py ──→ 风控进阶 Tab / 优化器 / 告警
```

| 模块 | 路径（新建） | 职责 |
|:---|:---|:---|
| 因子构建 | `backend/domain/risk_model/factors.py` | 因子收益序列（等权市场/行业/风格），来源为快照收益面板 |
| 协方差估计 | `backend/domain/risk_model/cov.py` | 因子模型协方差 + 收缩；输出 `(B, F, D)` 结构 |
| 风险分解 | `backend/domain/risk_model/decompose.py` | MCTR/CTR + 因子两级归因（勾稽校验内置） |
| B-L | `backend/domain/risk_model/black_litterman.py` | 后验收益；观点置信度 → Ω 对角元映射 |
| 服务 | `backend/services/risk_model_service.py` | 编排 + 模型产物缓存（按 快照+频率+因子集 键控） |
| 路由 | `backend/routers/risk_model.py` | §四端点 |

**红线**：收益数据一律快照绑定；B-L 观点缺置信度直接拒绝（`error_code: view_confidence_required`）；AI 生成观点必须带来源与时间戳（§9.7 有溯源）。

## 三、Pydantic Schema 草案

```python
class RiskModelRequest(BaseModel):
    universe: str
    data_snapshot_id: str
    lookback_days: int = 250
    factor_set: str = "default5"              # 市场+行业+市值+动量+波动
    shrink: bool = True                       # Ledoit-Wolf

class RiskModelArtifact(BaseModel):
    model_id: str
    data_snapshot_id: str
    factor_set: str
    annualized_vol: float
    factor_cov: dict[str, dict[str, float]]   # 因子协方差（稀疏存储仅非零）
    spec_vol: dict[str, float]                # 特异波动
    sample_window: tuple[date, date]
    method_note: str                          # 估计方法说明（展示层必须透出）

class RiskDecomposition(BaseModel):
    model_id: str
    portfolio_weights: dict[str, float]
    portfolio_vol: float
    holding_ctr: dict[str, float]             # 持仓风险贡献（和 = portfolio_vol，勾稽）
    factor_ctr: dict[str, float]              # 因子风险贡献
    reconciliation_error: float               # 必须 < 1%

class BLView(BaseModel):
    symbol: str
    direction: Literal["outperform", "underperform"]
    magnitude_pct: float                      # 相对幅度
    confidence: float                         # 0~1，必填
    source: str                               # "manual" / "ai:<session_id>"
    generated_at: datetime

class BLResult(BaseModel):
    posterior_returns: dict[str, float]
    implied_weights_preview: dict[str, float] # 无约束预览，正式求解走 §二十三
    views_applied: int
    tau: float
```

## 七、验收标准

| 维度 | 指标 | 验收线 |
|:---|:---|:---|
| 正确性 | 风险分解勾稽 | `reconciliation_error` < 1%（Pytest 断言） |
| 正确性 | B-L 极端情形 | 置信度→∞ 收敛观点收益；→0 收敛均衡（golden case） |
| 可复现 | 同快照+同参数 | 产物哈希一致 |
| 诚实性 | 观点无置信度 / 样本 < 60 日 | 拒绝或显式降级提示 |
| 性能 | 50 标的 × 250 日建模 | < 20s |
| 测试 | 覆盖率 | ≥ 80%（CI 门禁） |
