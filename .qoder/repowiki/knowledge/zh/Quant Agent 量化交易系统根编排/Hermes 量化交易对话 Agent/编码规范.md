- 工具类通过 `@register_tool` 装饰器声明，并暴露 `name`、`description`、`parameters` 与 `run` 方法，由 `ToolRegistry` 自动发现与注册。
- 对外部 HTTP 请求统一封装为 `BaseTool.rate_limit_aware_request`，检测 429/503 或响应体中的 rate_limited 信号并按 `retry_after_seconds` 退避重试。
- 缓存采用 L1 进程内存字典 + L2 Redis 双级结构，写路径先入内存再按需持久化，读路径命中 L2 后回写 L1 加速后续访问。
- Agent 对 LLM 调用的关键路径（非流式/流式/强制总结）统一通过 `_build_request_kwargs`、`_record_usage`、`_safe_execute_tool` 三个辅助函数收敛参数构造、token 计量与工具执行逻辑。
- 会话状态通过 `MemoryOperationsMixin` 提供 `_save_session`/`_load_session`/`_heal_memory`/`_compress_memory`/`_guard_before_llm` 等方法，宿主类仅维护 `messages`、`redis_client`、`session_id` 等状态字段。
- 工具结果缓存键由 `tool:cache:{name}:{sha256(json(sort_keys))}` 构成，TTL 优先取 `TOOL_CACHE_TTL_{NAME}` 环境变量，其次查内置表，最后回退到 `TOOL_CACHE_DEFAULT_TTL`。
