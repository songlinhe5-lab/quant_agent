本模块是后端对外暴露的 HTTP/WS 网关，由三层构成：
- 路由层（backend/routers/）：每个文件导出一个名为 router 的 APIRouter 实例，仅负责参数解析、校验与调用 app 层，不承载业务编排；按功能域划分为行情期权、投资组合交易、投研因子、风控回测、系统管理、数据源/数据湖六大子模块。
- 应用编排层（backend/app/）：提供 market_data、broker 等 Port 门面以及 oms_app、backtest_app、system_app、walk_forward_app、monte_carlo_app、grid_search_app、overfit_app 等用例入口，被各 router 统一 import 调用，形成「router → app_* → services/domain」的单向依赖链。
- 共享契约（backend/schemas/domain.py）：集中定义跨路由复用的 Pydantic 模型。
启动时 main.create_app() 依次注册全局中间件（AccessLog、CORS）、异常处理器、OpenAPI 标签与 OTEL，再按功能域 include_router(prefix='/api/v1')，根级仅保留 system_health、mcp 等基础设施路由；bootstrap.lifecycle.app_lifespan 在请求进入前完成全局 LLM 客户端与服务注册表初始化。
