- 所有对外暴露的异步函数统一以 `{"status": "success", ...}` 字典形式返回，错误路径抛出 `backend.core.exceptions.AppError` 并携带 HTTP status_code 与 detail。
- 对高延迟或易被并发穿透的接口采用「Redis 预读 + 模块级 `_xxx_locks` 异步锁池 + 双重检查锁」三段式缓存保护，TTL 附加 `random.randint` Jitter 防雪崩。
- 外部依赖（services、market_data、cep_engine、kline_warehouse 等）在函数体内按需 import，避免启动期循环导入并方便单测替换。
- 请求参数使用 Pydantic `BaseModel` 声明，字段带默认值与约束（如 `pattern`、`max_length`），并通过 `model_dump()` 兼容 Pydantic v1/v2。
- 数据库写操作遵循「db.add → db.commit → db.refresh」模式，并在异常分支统一执行 `db.rollback()` 后抛 AppError。
- 多源聚合接口对每个子任务用 `_safe(coro)` 包装 `asyncio.gather`，任一子任务失败返回 None 并由前端展示空态，绝不注入 Mock 假数据。
