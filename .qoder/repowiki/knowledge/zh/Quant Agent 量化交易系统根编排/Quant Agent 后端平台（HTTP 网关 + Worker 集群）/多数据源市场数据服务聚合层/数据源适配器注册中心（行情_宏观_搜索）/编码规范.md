- 每个适配器文件同时提供 DataSource 类与 ensure_*_registered() 函数，后者负责向 datasource_registry 进行幂等注册并返回已注册名称。
- fetch() 方法统一先校验 action 是否在 capabilities 内，再调用 data_source_router.fetch_xxx()，并将响应信封 {status:'success', data:...} 解包后通过 Result.make_success/make_error 返回。
- 健康检查 is_available()/health() 通过 data_source_router._nodes.get('<source>_master' 或 '<source>_remote') 读取远端节点状态，mode 固定返回 'remote'。
- 错误分类遵循统一模式：UNSUPPORTED_ACTION 标记为非重试错误，ROUTER_ERROR/FETCH_FAILED 标记为可重试错误，限流场景通过 Result.make_rate_limited 返回。
- 新增适配器需遵循基类模式（如 _RemoteMacroDataSource、_RemoteSearchDataSource），子类仅声明 source_key/name/capabilities，复用健康与 fetch 逻辑。
- __init__.py 中按业务分组集中注册，每个 ensure_* 调用被 try/except 包裹并记录 logger.warning，保证单源故障不影响整体注册流程。
