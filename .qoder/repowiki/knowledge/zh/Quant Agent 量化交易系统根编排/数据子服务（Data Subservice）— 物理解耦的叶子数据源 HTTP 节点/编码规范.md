- 每个数据源以独立的 `*_worker.py` 文件暴露 `handle_<source>(action, params)` 函数，由 `main.fetch_data` 通过 `_WORKER_IMPORTS` 延迟导入并按 action 分派。
- 重型/本地依赖型 SDK（akshare/tushare/futu/finnhub/fmp/fred/dbnomics/rbi/search）一律通过 `__import__` 延迟加载，缺失时返回 503，避免无依赖场景启动失败。
- Worker 层对业务异常统一捕获并返回带 `source` 字段的错误字典，同时用 `_internal.logger` 记录结构化日志。
- yfinance 子服务的所有限流/爬虫 IO 均经 `YFinanceService._run_guarded` 包裹，先过 `asyncio.Semaphore(YF_MAX_CONCURRENCY)` 再进 `circuit_breaker.call`，防止线程耗尽。
- Futu 相关操作统一走 `FutuService._route(action, params, local_handler=...)`，将具体 handler 方法作为参数传入，由 `FutuSourceRouter` 在当前 local 模式下调度。
- 节点能力通过 `DS_CAPABILITIES`/`NODE_CAPABILITIES` 环境串声明，`main._declared_capabilities()` 与 `nodeinfo.get_node_info` 共用同一解析逻辑，确保路由门控与注册信息一致。
- Redis 注册表操作统一使用 `async with redis.pipeline() as pipe:` 批量写入 nodes/heartbeats/stats/drain 键空间，保证原子性。
