模块按职责划分为三个目录：`system/` 存放 Agent 主脑运行时指令（HERMES.md）及索引说明（AGENT_SYSTEM.md），由 `HermesAgent` 通过 `DEFAULT_SYSTEM_PROMPT_PATH` 加载；`tasks/` 存放面向子模型或专用 LLM 调用的任务 Prompt（情感分析、选股 NLP→DSL、标题生成等），每个文件对应后端服务中的具体调用点；`templates/_template.md` 提供新 Prompt 的标准化骨架。所有 Prompt 统一采用 YAML Front Matter 声明 id、name、target_model、input_variables、output_format、last_tested、eval_score、changelog 等元信息，配合 `README.md` 中定义的变更流程（修改 → 运行 Eval → PR 附带对比 → 更新元数据）实现可审计的版本管理。该模块仅作为静态资源被 Python 代码读取，无自身执行逻辑。
