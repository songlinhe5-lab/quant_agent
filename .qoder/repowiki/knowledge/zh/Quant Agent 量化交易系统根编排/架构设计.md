根目录作为跨语言系统的编排中心：
- 部署编排：`docker-compose.master.yml` 定义 quant-agent（HTTP）、quant-worker（后台任务）、data-subservice（叶子数据源节点）、Redis、pgvector、私有镜像 Registry、Prometheus/Grafana/Tempo 的容器网络 `quant-internal`；各 node 系列 compose（node-bj/s1/s2/s3/s4）复用同一 data-subservice 镜像并以 `DS_CAPABILITIES` 环境变量裁剪能力。
- 开发入口：`Makefile` 提供 `dev-infra/dev-api/dev-worker/dev-frontend/dev` 等命令，统一启动基础设施、FastAPI、Worker 与 Vite 前端，并注入 `SKIP_YF_TEST` 等环境变量。
- 跨语言契约：`shared/proto/market.proto` 由后端生成 Python gRPC stub，同时通过 `package.json` 的 `proto:gen` 脚本用 protobufjs 为前端生成 JS/TS 类型，前后端共享市场数据结构。
- 依赖隔离：`pyproject.toml` 将重型数据源 SDK（yfinance/tushare/akshare/futu-api）放入 `optional-dependencies.datasource-all`，主服务默认不安装，仅 data_subservice 节点安装，实现运行时能力裁剪。
- 可观测性：`prometheus.yml`、`grafana/provisioning/*`、`tempo/tempo.yaml` 集中配置指标采集、告警规则与分布式追踪，供所有子服务上报。
- CI/CD：`.github/workflows/`（backend.yml、frontend.yml、eval.yml、prompt_governance_ci.yml、security.yml、compose-hygiene.yml）与 `docker-publish.yml`、`registry-config.yml` 构成镜像构建→私有 Registry→多地域节点拉取的发布流水线。
