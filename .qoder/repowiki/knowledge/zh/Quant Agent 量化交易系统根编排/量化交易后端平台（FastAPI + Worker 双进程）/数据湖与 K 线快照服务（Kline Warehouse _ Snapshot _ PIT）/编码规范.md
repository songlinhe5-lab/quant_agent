- 对外部依赖（Redis、SQLAlchemy Session、metrics、survivorship bias tracker）采用方法内延迟 import，避免循环导入与测试环境缺失依赖导致的启动失败。
- 快照 ID 统一使用 `snap_{YYYYMMDD}` 格式，ticker 文件名通过 `ticker_to_filename` 将 `.` `/` 替换为 `_` 后再加 `.parquet` 后缀，反向还原用于列出标的。
- Manifest 采用确定性 JSON（`sort_keys=True, separators=(",",":")`）计算 sha256 指纹，且支持 `sha256:` 前缀兼容旧数据。
- 所有 I/O 阻塞操作（Parquet 读写、tar 打包、S3 写入）通过 `asyncio.to_thread` 放入线程池执行，保持异步事件循环不被阻塞。
- 长任务通过 Redis 分布式锁保护（`quant:lock:snapshot_create:*`、`quant:lock:snapshot_retention`、`quant:lock:kline_sync:*`），锁超时时间固定为 7200s 或 3600s。
- 可选能力（R2 冷归档、universe sidecar 导出、质量门控函数）通过构造函数注入或全局单例懒加载，未配置时静默降级而非抛错。
