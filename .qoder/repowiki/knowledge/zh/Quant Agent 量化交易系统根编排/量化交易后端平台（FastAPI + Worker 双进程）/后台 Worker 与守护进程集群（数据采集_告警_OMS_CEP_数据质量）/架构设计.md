本模块以 `backend/workers/` 为进程边界，按职责划分为多个独立子目录，每个子目录对应一个可被 worker.py 启动的 asyncio 守护进程；`backend/services/cep/` 与 `backend/services/data_quality/` 提供无状态服务层供上层订阅。

- 采集器插件化：`collector_registry.CollectorDef` + `COLLECTORS` 字典集中声明各采集器（akshare/finnhub/yfinance/fmp/cboe_pc_ratio/quote_publisher），统一通过 `start_collector_daemons` 遍历 factory 启动 Task，新增采集器只需注册工厂函数，零具体 import 耦合（BE-ARCH-03）。
- 市场守护进程：`market/daemon.py` 在 Master 节点聚合 Finnhub 新闻、个股新闻、宏观核弹、财报发布、内幕交易跑马灯等轮询任务，全部经 `DataSourceRegistry` → `data_source_router` 远程调用 data_subservice，主服务不再直连 Finnhub WS。
- 告警引擎：`alert_engine.AlertEngine` 订阅 Redis `quant:quotes:stream`，按价格类/指标类/自由表达式三类规则评估，事件经 `AlertDispatcher` 推送并持久化到 `quant:alerts:*` 键空间。
- OMS 算法拆单：`oms/algo_engine.py` 实现 TWAP/VWAP/ICEBERG/POV/IS 五种算法，订单状态通过 Redis Hash/List 持久化并支持断线恢复；LIVE/SANDBOX 模式由 `quant:oms:trading_mode` 切换。
- 纸面结算：`paper/settlement_daemon.PaperSettlementDaemon` 每 5 分钟巡检 HK/US 市场，盘后 EOD 写 `paper_nav_daily`，盘中写 Redis 环形 288 点 NAV 快照，支持补结算与周度对账。
- CEP：`services/cep/cep_engine.CEPEngine` 维护每标的 K 线滑动窗口（WINDOW_SIZE=60），收到 tick 后计算技术指标并通过 `evaluate_expression` 匹配用户表达式，冷却期 300s 防抖。
- 数据质量：`services/data_quality/monitor.DataQualityMonitor` 按数据源维度统计脏数据率、延迟、异常计数，并导出 Prometheus Gauge/Counter 暴露给 Grafana。

依赖方向：workers → services（cep/data_quality/alert/datasource/router）→ core（redis_client/database/metrics），worker 之间不直接互相 import，仅共享 Redis 键空间与 DataSourceRouter。
