- 每个守护进程以 async 函数 + `while True` 轮询循环实现，内部 try/except 包裹异常防止进程退出，并通过 `asyncio.sleep` 控制频率。
- Redis 去重采用 `SET key value NX EX ttl` 模式（如 `quant:news:dedup:*`、`quant:lock:paper_settle:*`），保证幂等与过期自动清理。
- 对外部依赖（LLM、datasource router、futu service）采用函数内局部 import 延迟加载，避免启动时强耦合。
- 长生命周期对象以模块级单例导出（如 `algo_engine`、`paper_settlement_daemon`、`cep_engine`），供其他模块直接引用。
- 进程状态与进度通过 Redis Hash/List 持久化（如 `quant:oms:algo:active`、`quant:alerts:rules`、`quant:alerts:events`），重启后可从 Redis 恢复。
- 采集器遵循 `CollectorDef(factory=xxx.start)` 插件注册约定，factory 返回协程列表并由 `start_collector_daemons` 统一封装为 `asyncio.Task`。
