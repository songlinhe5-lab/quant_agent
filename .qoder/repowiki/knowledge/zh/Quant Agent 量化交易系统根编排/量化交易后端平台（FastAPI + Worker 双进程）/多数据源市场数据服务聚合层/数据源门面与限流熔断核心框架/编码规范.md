- 所有数据源返回统一 `Result` 结构并通过 `Result.make_success/make_error/make_rate_limited/make_degraded` 工厂构造，禁止直接 new Result。
- 错误一律通过 `ErrorInfo.normal/rate_limited/quota_exhausted/ip_blocked` 快捷构造器创建，并使用 `ErrorCategory` 枚举区分限流类与普通错误。
- 限流状态对象使用 `@dataclass(slots=True, frozen=True)` 声明不可变数据类，并提供 `to_dict` / `from_dict` 双向序列化。
- 全局可共享的 Throttler/Analyzer 通过 `rate_limit_registry.get_throttler(name)/get_analyzer(name)` 获取，避免重复实例化。
- 线程安全组件内部使用 `threading.Lock()` 保护可变状态，并在属性访问路径中加锁（如 Throttler/Analyzer 的所有读写方法）。
- Prometheus 指标采用延迟导入模式（在首次使用时 import backend.core.metrics），避免循环依赖与冷启动开销。
