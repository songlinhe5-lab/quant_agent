- 每个数据源 Service 方法统一返回带 `status`/`data`/`source` 字段的字典，错误分支额外携带 `error_category` 以区分 RATE_LIMIT/IP_BLOCKED/QUOTA_EXHAUSTED/NORMAL。
- 对外部 HTTP 请求统一使用 `httpx.AsyncClient(timeout=...)` 并挂载 `httpx_log_request`/`httpx_log_response` 事件钩子，便于链路追踪。
- 所有可缓存的数据在命中后通过 `redis_client.setex` 写入，key 遵循 `quant:<domain>:<entity>:...` 命名空间，并按数据类型设置差异化 TTL（如财报日历 43200s、内幕交易 12h、历史 K 线 1h）。
- 对易触达频控的外部 API（Finnhub 429/403、Tushare 令牌桶）在请求前或异常路径中调用限流/熔断机制，并将限流类错误标记为不可重试。
- 通过环境变量读取敏感凭据（API Key/Token），禁止硬编码；未配置时直接返回 `status: error/skipped` 而非抛错。
- Tushare 适配器通过 `TushareDataSource` 实现 `DataSourceInterface` 并以 `ensure_tushare_registered` 幂等注册到 `datasource_registry`，使上层统一经 Registry.fetch 访问而无需感知具体数据源。
