- 每个路由文件以模块级注释声明所实现的工单编号（如 TRADE-03、PT-01b/PT-02a）及 URL 端点清单，作为对外契约文档。
- 请求体统一使用 Pydantic `BaseModel` 定义，字段附带默认值与类型约束（如 `Field(max_length=...)`、`Optional[...]`）。
- HTTP 响应采用统一的 `{"status": "success", "data": ...}` 结构，错误路径返回 `{"status": "error", "message": ...}`。
- 数据库会话通过 `Depends(get_db)` 注入函数参数，而非全局变量，保证每个请求独立 Session。
- 外部 I/O（kline_warehouse、redis_client）在 router 内按需 import，避免启动期冷启动开销，并在异常时降级到模拟数据或空结果。
- 业务异常统一捕获后记录 `logger.error/warning` 并以 `HTTPException(status_code, detail=...)` 向上抛出，保持端点错误码一致。
