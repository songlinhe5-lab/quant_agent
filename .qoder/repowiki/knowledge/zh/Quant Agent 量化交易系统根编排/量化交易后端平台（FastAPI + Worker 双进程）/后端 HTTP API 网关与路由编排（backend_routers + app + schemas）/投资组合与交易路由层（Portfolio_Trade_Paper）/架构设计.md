本模块由三个并列的 FastAPI `APIRouter` 组成，按业务域拆分：
- `portfolio.py`：前缀 `/portfolio`，标签 `Portfolio Optimization`，提供组合优化、有效前沿、多模型对比三个 POST 端点；通过内部 `_fetch_returns` 优先从 `backend.services.datalake.kline_warehouse` 拉取 K 线并矢量化计算日收益率，失败时降级到 `_generate_mock_returns` 生成带相关性的模拟数据，再调用 `backend.domain.portfolio_optimizer` 执行 Markowitz / Risk Parity / Max Sharpe / Equal Weight 等策略。
- `trade.py`：前缀 `/trade`，标签 `OMS`，仅做参数透传与鉴权注入（`dependencies=[Depends(get_current_user)]`），所有用例编排委托给 `backend.app.trade_app` 中的 `place_order/get_account_info/get_portfolio/get_trades`，并通过重新导出 `_trade_locks` 满足测试夹具对共享锁对象的引用。
- `paper.py`：前缀 `/paper`，标签 `Paper Trading`，实现纸面组合的 CRUD、暂停/恢复/关闭、成交流水分页、日终 NAV 序列以及 paper vs benchmark 对比（跟踪误差、累计偏离、Sharpe、最大回撤），依赖 `backend.services.paper_ledger_service` 与 `backend.domain.performance`，benchmark NAV 优先从 Redis 快照读取并 fire-and-forget 回填。
依赖方向单向向下：router → domain/service/app 层，不直接访问数据库（除 `get_trades` 通过 `Depends(get_db)` 获取 SQLAlchemy Session）。
