- 每个路由文件导出一个名为 router 的 APIRouter 实例，由 main.create_app 集中 include_router(prefix=API_PREFIX) 挂载。
- 路由层只做参数解析与调用，业务编排逻辑下沉至 backend/app 下的 *_app.py 用例入口，禁止在 router 内直接写业务分支。
- 跨路由共享的请求/响应体统一放在 backend/schemas/domain.py 中以 Pydantic model 定义，避免在各 router 重复声明。
- 新增路由必须遵循「router → app_* → services/domain」单向依赖，不得反向引用或跨域直接耦合。
- 所有外部 I/O 通过 core/ 提供的异常处理器与中间件统一捕获与记录，路由内不再自行 try/except 业务异常。
