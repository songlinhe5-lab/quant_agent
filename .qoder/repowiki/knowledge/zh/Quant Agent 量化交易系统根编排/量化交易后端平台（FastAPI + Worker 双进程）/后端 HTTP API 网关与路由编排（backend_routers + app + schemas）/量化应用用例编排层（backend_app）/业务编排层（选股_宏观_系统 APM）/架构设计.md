本模块由三个并列的 `*_app.py` 文件组成，每个文件对应一个业务域，作为 FastAPI router 之上的「编排层」：
- `screener_app.py`：选股编排，集中 DSL 转译、Futu 多市场并发扫盘、Redis 缓存+细粒度锁防击穿、服务端排序/分页/去重、RAG 规则管理、订阅任务持久化、横截面筛选、组合回测与 CEP 异动规则 CRUD；通过显式导入 `backend.services.screener.screener_service`、`backend.app.market_data`、`backend.core.redis_client` 暴露依赖边界，便于单测 patch。
- `macro_app.py`：宏观数据编排，提供经济日历、财报日历、情绪风向标、板块资金流、跨市场资金流向、新闻等接口；核心 `_fetch_macro_calendar_data` / `_fetch_earnings_calendar_data` / `get_capital_flow_dashboard` 采用「Redis 缓存 + 模块级 `_macro_locks` 异步锁池 + 双重检查锁 (DCL)」模式，并调用 `macro_calendar_aggregator`、`market_data`、`llm_service`、`sentiment_service` 等多源服务做聚合与 LLM 前瞻推演，失败时走 `_fallback_no_data()` 返回空数据而非假数据。
- `system_app.py`：系统 APM 编排，提供健康检查、集群快照、Prometheus 指标快照、24h 性能统计、线程水位聚合，所有子探测均 try/except 隔离，保证整体健康态可降级。
依赖方向单向向下：router → app_* → services/core/market_data/redis_client，不反向依赖 router。
