本目录按 BE-ARCH-01/02 规范组织：顶层 `broker.py`、`market_data.py`、`iv_history_service.py` 充当 Port 门面，仅做依赖注入与别名导出，禁止路由层直连 `services.*_service`；各 `_app.py`（oms/trade/backtest/system/macro/screener/grid_search/monte_carlo/walk_forward/overfit）作为用例编排器，将 HTTP 请求转换为对 Broker/OMS/行情/引擎的调用并处理缓存、降级与异常映射；`backtest/`、`eval/`、`rag/`、`research/` 子包承载领域内聚的辅助服务（组合回测报告、评估 Runner、RAG 治理、深度研究），被对应 `_app.py` 通过相对 import 引用。新增编排逻辑必须进入本目录而非扁平 `backend/services/*.py`，从而形成“路由层 → app 用例编排 → services 适配器”的单向分层。
