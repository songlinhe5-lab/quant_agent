- 所有外部依赖（broker / market_data / redis_client / oms_service / models）在模块顶部显式导入，使 router 仅承担鉴权与参数校验，便于单元测试对 `backend.app.trade_app.<dep>` 进行 patch。
- 对外部服务调用统一以 dict 形式返回 `{status, data/message}`，并在调用方用 `if result.get('status') == 'error'` 分支后抛出 `AppError` 统一错误码。
- 关键热路径（如账户资产查询）使用 Redis 缓存 + `asyncio.Lock` 双重保护，避免高并发下重复穿透到券商 API。
- 数据库操作在需要时通过 `from backend.core.database import SessionLocal` 动态创建独立会话，避免与 FastAPI 依赖注入生命周期冲突。
- OMS 熔断相关日志统一使用 `logging.getLogger('OMS')` 并以 emoji 前缀（🚨/✅/⚠️）区分级别，便于日志检索。
