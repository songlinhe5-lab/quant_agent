本模块由三个并列的 `*_app.py` 文件组成，每个文件对应一种优化场景：`walk_forward_app.py` 定义共享的 `STRATEGY_REGISTRY` 与 `resolve_strategy` 工厂，被 `grid_search_app.py` 和 `monte_carlo_app.py` 复用；三者均通过 `backend.app.backtest_app.load_backtest_frame` 获取行情 DataFrame，再构造 `VectorConfig` 并调用 `backend.engine` 下的 `WalkForwardRunner` / `GridSearchRunner` / `MonteCarloRunner` 执行计算，最后将报告对象 `.to_dict()` 包装为 `{status: 'success', data: ...}` 返回。依赖方向单向指向 `engine` 层与 `backtest_app`，不反向依赖；异常统一以模块级 `*Error` 类（继承 Exception 并暴露 `message`）捕获下游 `BacktestDataError` / `ValueError` 后抛出，供上层路由统一处理。
