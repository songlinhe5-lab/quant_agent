- 每个用例文件定义一个 `@dataclass` 请求参数类（如 `GridSearchParams`、`MonteCarloParams`、`WalkForwardParams`），字段包含 ticker、period、interval、initial_capital、commission_pct、slippage_pct、strategy_key 等通用回测参数。
- 每个用例文件定义同名 `*Error(Exception)` 类，并在 `__init__` 中保存 `message` 属性，用于向上层路由传递结构化错误信息。
- 异步入口函数统一命名为 `run_<scenario>(req: <Params>) -> Dict[str, Any]`，内部先解析策略、再拉取行情、再构造 Runner 并调用 `runner.run(...)`，最后将报告 `.to_dict()` 包装为 `{status: 'success', data: payload}` 返回。
- 对下游异常做分层转换：`BacktestDataError` 与 `ValueError` 分别被捕获并转换为对应用例的 `*Error`，使用 `from e` 保留原始异常链。
- 在调用 Runner 前对 DataFrame 列名执行统一小写化（`df.rename(columns={c: c.lower() for c in df.columns if c.lower() != c})`），确保信号逻辑可消费不同来源的列名。
- `grid_search_app.py` 与 `monte_carlo_app.py` 通过导入 `walk_forward_app.STRATEGY_REGISTRY` 与 `resolve_strategy` 复用策略注册机制，新增策略只需在该 registry 中登记即可被所有用例发现。
