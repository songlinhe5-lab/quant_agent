本模块由三个并列的 FastAPI `APIRouter` 组成，统一挂载到主应用：
- `auth.py`：定义 `/auth` 路由，集中实现 JWT 签发（Access Token 15 分钟 + Refresh Token 30 天滑动续期）、Cookie 安全配置（生产环境 SameSite=None+Secure，开发 Lax）、密码登录、Google OAuth2 令牌验证（自动注册用户）、刷新与登出；通过 `Depends(get_current_user)` 暴露可复用的鉴权依赖，并调用 `backend.services.audit_service.log_audit` 记录审计日志。
- `system.py`：定义 `/system` 路由，聚合 APM 看板能力——观测性总览（tick_cache + FMP credit，经 HTTP 拉取子服务 `/metrics` 并解析 Prometheus 文本，不可达时回退本地估算）、数据质量汇总、性能日志查询与聚合（SQLAlchemy 聚合 + `asyncio.to_thread` 避免阻塞事件循环）、APM 仪表盘、线程水位监控、LLM token 用量统计（`token_usage_store`），所有读操作均通过 `get_current_user` 保护。
- `alert.py`：定义 `/alert` 路由，仅做请求校验与 HTTP 映射，业务逻辑全部委托给 `backend.app.alert_app`（遵循「路由层薄、编排逻辑下沉」的分层约定），并提供 WebSocket `/ws` 实时推送（基于 Redis PubSub `quant:alerts:push`，连接鉴权使用 query string 中的 JWT，避免 router 级依赖污染 WS 上下文）。
依赖方向单向向外：路由层 → `backend.core.*` / `backend.services.*` / `backend.app.*`，不反向被业务模块引用。
