- 所有需要认证的接口通过 `Depends(get_current_user)` 声明式鉴权，而非在函数体内手动解析 Token。
- 路由文件顶部创建独立的 `APIRouter(prefix=..., tags=[...])`，并在文件末尾以 `router = ...` 形式导出，便于主应用按模块 mount。
- 对外部依赖（如 `backend.app.system_app`、`backend.workers.collectors.fmp`、`backend.services.data_quality.monitor`）采用函数内 `import` 延迟导入，避免启动时循环依赖或冷启动开销。
- 数据库访问在路由中通过 `SessionLocal()` 上下文管理器或 `Depends(get_db)` 获取 Session，并在异常分支统一记录日志后抛出。
- 敏感操作（登录、改密、登出）统一调用 `log_audit(db, action=..., detail=..., request=request, user_id=...)` 记录审计日志。
- HTTP 响应体统一采用 `{"status": "success", "data": ..., "timestamp": ...}` 的结构化格式，便于前端统一处理。
