- 每个文件定义一个 `APIRouter(prefix=..., tags=[...])` 实例，并以同名字符串作为 OpenAPI tag 进行分组。
- 路由函数保持极薄：仅接收 FastAPI 参数/请求体，直接 `await` 调用对应 app/service 层函数并返回字典或对象，不包含业务判断。
- 需要数据库访问的路由统一通过 `db: Session = Depends(get_db)` 声明式注入，而非全局获取。
- 受保护路由统一通过 `current_user: models.User = Depends(get_current_user)` 注入当前用户，或在 Router 构造时以 `dependencies=[Depends(get_current_user)]` 全局挂载。
- 请求体使用 Pydantic `BaseModel` 子类显式声明字段及默认值，避免使用裸 dict 作为入参。
- 对资源级操作（如订阅、屏幕）采用自定义依赖（如 `get_subscription`）在路由层完成存在性校验并抛出 `HTTPException(404)`，再交由业务函数处理。
