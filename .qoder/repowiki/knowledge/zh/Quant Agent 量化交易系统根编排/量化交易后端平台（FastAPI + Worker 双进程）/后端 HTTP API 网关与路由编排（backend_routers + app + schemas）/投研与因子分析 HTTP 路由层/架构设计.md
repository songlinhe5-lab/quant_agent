本模块由三个独立的 FastAPI `APIRouter` 组成，分别挂载到 `/research`、`/screener`、`/factor` 前缀，并通过 `tags` 在 OpenAPI 中分组。
- `research.py`：无鉴权中间件，暴露 `/research/meta`（读取 `lifecycle.global_registry` 与 `settings.llm_model`）和 `/research/deep-report`（调用 `backend.app.research.deep_research.deep_research_pipeline.run`）两个端点。
- `factor.py`：无鉴权，通过 `backend.services.factor_mining.factor_miner.FactorMiner` 暴露 LLM 因子建议 (`/factor/suggest`) 与参数网格搜索 (`/factor/search`)。
- `screener.py`：作为“薄路由”边界，所有业务编排下沉至 `backend.app.screener_app`；路由层仅负责参数透传、依赖注入（`Depends(get_db)`、`Depends(get_current_user)`）、404 校验（自定义 `get_subscription` 依赖），并重新导出 app 层的 Pydantic 模型供测试使用。除 `/run` 为公开端点外，其余路由默认挂载全局 `dependencies=[Depends(get_current_user)]` 实现统一鉴权。
依赖方向单向向下：router → app/services/core，不反向引用上层模块。
