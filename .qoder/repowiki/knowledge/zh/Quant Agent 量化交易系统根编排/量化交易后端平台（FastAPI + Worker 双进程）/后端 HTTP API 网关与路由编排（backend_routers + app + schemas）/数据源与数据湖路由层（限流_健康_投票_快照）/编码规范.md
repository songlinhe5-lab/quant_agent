- 每个文件定义一个 `APIRouter(prefix=..., tags=[...])` 并集中注册该领域的所有端点，保持路由按业务域拆分。
- 对外响应统一包装为 `{status, message, data, timestamp}` 结构（见 `datalake.py` 的 `_ok`），便于前端一致解析。
- 需要外部适配器时才在函数体内 `from ... import ensure_*` 惰性导入，避免启动期循环依赖与冷启动开销。
- 对共享可变状态（如测试链接的全局锁、per-source 锁字典、最后触发时间戳）使用模块级 `asyncio.Lock`/`Semaphore` 配合 `os.getenv` 配置的可调阈值进行并发防护。
- Redis 访问采用 `try/except` 包裹并在失败时回退到内存口径或返回空结果，保证看板与投票功能在 Redis 不可用时仍可降级运行。
- 鉴权型路由通过 `Depends(get_current_user)` 注入当前用户，非鉴权路由则通过 JWT 参数或无需认证的方式区分访问级别。
