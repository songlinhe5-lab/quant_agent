- 所有动态策略源码在执行前必须经过 `_verify_safe_code` 进行 AST 级安全检查，再放入带 `SAFE_BUILTINS` 的命名空间 `exec`。
- 策略执行体统一包裹在 `SandboxTimeoutTracer(timeout_seconds=...)` 上下文管理器中，以超时/内存熔断保护不可信代码。
- 向 VectorBT 提交信号前先通过 `_prepare_df` 规范化 DataFrame：展开 MultiIndex 列名、去重、补齐小写 ohlcv 列。

- 从 VectorBT 统计结果提取指标一律使用 `_safe_stat(stats, key)` 包装，避免 NaN 或键缺失导致异常。
- 进度上报统一通过模块内 `_emit_progress(progress_queue, pct, stage, detail)` 函数推送字典包，支持 None 队列静默跳过。
