- 生产策略统一继承 `BaseStrategySandbox`，并通过重写 `_calculate_indicators` 和 `_generate_signals` 两个受保护方法来定义策略逻辑。
- 策略参数集中在 `__init__` 中声明并保存为实例属性，便于回测时灵活配置窗口、倍数等超参。
- 技术指标计算结果直接写入 `self.df` 的新列（如 `short_ma`、`atr`、`signal`），由基类在回测循环中消费。
- ATR 计算统一遵循 True Range 三步法（high-low、|high-prev_close|、|low-prev_close| 取最大值后滚动平均）。
- 均线类型通过 `Literal['SMA', 'EMA']` 参数化，在指标计算分支中选择 rolling mean 或 ewm span 计算。
