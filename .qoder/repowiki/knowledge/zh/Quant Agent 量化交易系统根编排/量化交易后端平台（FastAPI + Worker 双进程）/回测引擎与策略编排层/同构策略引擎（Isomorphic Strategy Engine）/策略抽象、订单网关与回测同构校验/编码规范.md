- 策略通过继承 `Strategy` 抽象基类实现，仅覆盖 `on_bar` 等生命周期方法，禁止在策略内直接 import service/redis/futu，所有外部能力经 `StrategyContext` 获取。
- 订单执行采用 Protocol 抽象（`OrderExecutor`）+ 具体执行器（`SimBrokerExecutor`/`OmsExecutionAdapter`）的组合，由 `ExecutionGateway` 根据 `GatewayMode` 动态路由。
- 对外返回的数据结构统一使用 `dataclass`（如 `SafetyLockStatus`、`DivergencePoint`、`IsomorphismReport`、`OverfitReport`），并提供 `to_dict`/`summary` 等序列化辅助方法。
- 关键阈值以类常量或配置 dataclass 集中声明（如 `RETURN_TOLERANCE_PCT`、`OverfitConfig`），便于调参与测试断言。
- 实盘相关逻辑通过延迟 import（`from backend.services.oms_service import get_oms_service`）避免启动期强依赖，仅在首次调用时解析。
