本模块由三个相互协作的纯接口层文件组成，构成策略与引擎之间的稳定边界：
- `clock.py`：通过 `Clock` Protocol + `SimClock`/`WallClock` 双实现，将时间源抽象为可注入依赖；`SimClock` 由 Driver 逐 bar 推进且禁止回退，`WallClock` 返回 UTC 墙钟。
- `context.py`：以 `StrategyContext` Protocol 暴露策略唯一 API 面（元信息、数据查询 history/quote/financial/universe、账户 position/cash/equity、执行 order/cancel/open_orders、日志 log、订阅 subscribe），所有数据查询隐式 as-of ctx.now 以架构级防前视；`BaseContext` 提供公共基类供 Driver 继承并注入 Clock。
- `contracts.py`：使用 Pydantic BaseModel 定义跨进程/跨模式的数据契约（Bar、QuoteSnapshot、OrderIntent、OrderUpdate、Position、RunManifest），并通过 field_validator/model_validator 在构造时强制约束（如 dt 必须带 UTC 时区、LIMIT 单必填 limit_price）。
依赖方向单向：`context.py` 仅引用 `contracts.py` 中的类型（TYPE_CHECKING 下导入以避免循环），`clock.py` 不依赖其他两个文件；三者共同作为策略代码不可见的黑盒契约层。
