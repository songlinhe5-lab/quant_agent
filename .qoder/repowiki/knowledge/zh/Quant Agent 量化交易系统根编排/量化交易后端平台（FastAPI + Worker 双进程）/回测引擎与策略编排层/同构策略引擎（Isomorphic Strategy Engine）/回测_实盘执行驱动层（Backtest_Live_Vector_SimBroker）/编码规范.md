- 每个驱动以 dataclass 定义配置类（`BacktestConfig`/`LiveDriverConfig`/`VectorConfig`/`SimBrokerConfig`）并以同名 Driver/Executor 类暴露 run/start 入口。
- Context 实现继承 `BaseContext`，将数据面（history/quote/financial/universe）、账户面（position/cash/equity）、执行面（order/cancel/open_orders）三组方法分别集中实现。
- 对外部重依赖（Redis、KlineCacheEngine、MarketSession、PIT Store、vectorbt）采用函数内部 import，避免模块导入期的硬依赖。
- 回测主循环严格遵循「先撮合挂单/止损 → 再驱动 strategy.on_bar → 最后 dispatch_fills」的顺序，确保策略无法看到本 bar 内尚未发生的成交。
- DataFrame 预处理统一做去空、MultiIndex 扁平化、列名去重与小写化（Open→open 等），在 BacktestDriver 与 VectorExecutor 中重复出现。
- 结果对象使用 dataclass（`BacktestResult`/`VectorResult`）并包含 metrics、equity_curve、trades、manifest/signals 等标准化字段，便于上层统一消费。
