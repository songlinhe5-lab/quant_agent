模块由四个职责正交的文件组成，构成回测-实盘同构引擎的核心边界：
- strategy.py：定义 `Strategy` 抽象基类，暴露 `on_init/on_bar/on_order_update/on_stop` 生命周期钩子以及可选的 `signals` 矢量化快路径；策略仅依赖 `StrategyContext`，禁止直接 import service/redis/futu，从而屏蔽运行环境差异。
- gateway.py：通过 `ExecutionGateway` + `OrderExecutor` Protocol 实现订单统一出口，按 `GatewayMode`（BACKTEST/PAPER/LIVE）路由到 `SimBrokerExecutor` 或 `OmsExecutionAdapter`；`SafetyLockStatus` 用三条件（环境变量 `REAL_TRADE_EXECUTE`、交易模式 LIVE、kill_switch 未触发）做安全门控，失败时降级为 paper 语义；`client_order_id` 基于 tag+run_id 哈希实现幂等去重。
- verify.py：`IsomorphismVerifier` 对同一策略并行运行 `BacktestDriver`（事件驱动）与 `VectorExecutor`（矢量化），比较收益、回撤、交易数并定位分歧点，作为网格寻优结果的唯一一致性防线。
- overfit.py：`OverfitAnalyzer` 消费网格结果，计算 Deflated Sharpe Ratio（DSR，Bailey & López de Prado 2014）校正多重试炼选择偏差，并通过 `detect_param_cliffs` 检测相邻参数格夏普悬崖，输出 `OverfitReport`。
依赖方向单向：verify 依赖 strategy、backtest/vector drivers；overfit 仅消费网格结果；gateway 通过 Protocol 解耦 SimBroker/OmsExecutionAdapter，避免主服务直接依赖 futu SDK。
