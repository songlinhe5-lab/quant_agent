- 服务类以模块级全局单例暴露（如 `risk_engine = RiskEngine()`、`margin_service = MarginService()`），调用方直接 import 实例而非自行构造。
- 对外部数据源调用统一采用 `asyncio.gather(..., return_exceptions=True)` 并发拉取并按 `status == 'success'` 判断成功，失败则记录日志并降级为 partial/error。
- 数值型指标计算函数对空输入（无持仓/无 K 线/序列过短）返回零值或空结构，避免抛异常，保证上层面板渲染稳定。
- margin 数据源通过继承 `BaseMarginSource` 并实现 `fetch(as_of)` 接入，使用统一的 `_http_get_json/_http_get_text` 封装 aiohttp 请求与超时处理。
- 多源聚合采用“高优先级源优先、字段级互补合并”策略（`_merge_snapshot`），不同来源的相同字段保留首个非空值，`sources`/`note` 列表/字符串特殊合并。
- 所有跨进程共享的计算结果先查 Redis 缓存（带 key 前缀 `quant:risk:*` / `quant:margin:*`），读失败才回源计算并写回，TTL 按场景区分（30s/86400s）。
