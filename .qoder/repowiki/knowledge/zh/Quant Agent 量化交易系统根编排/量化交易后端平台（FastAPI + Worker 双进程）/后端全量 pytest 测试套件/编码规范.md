- 每个被测模块对应一个 `test_xxx.py` 文件，文件名与被测模块名一致，便于通过 pytest 路径定位。
- HTTP 路由测试优先构造最小 FastAPI 实例并 `include_router` 仅挂载目标路由，避免加载完整应用上下文。
- 对外部依赖（Redis、数据库、Futu/yfinance/httpx）一律通过 `unittest.mock.patch` 或 conftest 中的 autouse fixture 替换为 AsyncMock/MagicMock，禁止真实网络调用。
- 涉及全局状态（circuit_breaker、rate_limit_registry、app.dependency_overrides）的测试使用 `autouse` fixture 在前后各执行一次 reset/clear，确保用例间完全隔离。
- 需要跳过外部 mock 的用例通过自定义 `no_mock_external` marker 显式声明，而非在单个测试内临时恢复 patch。
- 架构合规性测试以静态正则扫描 `backend/routers` 源码中 forbidden import 的方式断言，不依赖运行时导入。
