本模块由五个并列子服务组成，按领域划分职责：
- `macro/`：宏观数据接入层，封装 FRED（经 `data_source_router.fetch_fred`）、RBI、Macro Calendar、Sentiment Tracker 等外部源，统一通过 Redis 缓存并做归一化；`__init__.py` 重导出公共符号。
- `fund_flow/`：三市场（A股/港股/美股）板块资金流聚合器，`service.FundFlowService.get_sector_fund_flow` 用 `asyncio.gather` 并发拉取各市场独立实现（`a_share_sector.py`、`hk_sector.py`、`us_sector.py`），任一失败不影响整体，返回 `success/partial/error` 状态。
- `sentiment/sources/cboe_pc_ratio.py`：独立的情绪数据源，从 CBOE 官网 HTML 解析 TOTAL P/C Ratio，输出与 yfinance VIX 对齐的 records JSON，供上层 sentiment tracker 消费。
- `market_review/`：每日复盘引擎，`generator.generate_market_review` 分四阶段——并行采集指数/资金/新闻/情绪/板块 → 零幻觉校验（核心数据缺失则跳过 LLM 定性）→ 调用 `ai_narrator.llm_service.generate_pydantic` 产出结构化分析 → 组装 `MarketDailyReview` 模型并持久化到 `storage.save_market_review`；`models.py` 定义 Pydantic 实体与枚举（MarketType/Style/SentimentLevel）。
- `morning_briefing/`：盘前早报引擎，`MorningBriefingGenerator.generate` 编排四个工具（宏观日历、行情 QUOTE、宏观新闻、情绪历史）+ 可选回测健康度，拼接 Markdown prompt 经 LLM 生成早报，失败时走 `_fallback_markdown` 兜底。
依赖方向单向向下：review/briefing 通过 `ToolRegistry` 调用上游工具（broker/macro/news/sentiment），不反向依赖 fund_flow 或 macro 内部实现；所有外部 HTTP 请求均被 try/except 包裹并以 None/降级响应形式返回，保证 daemon 级容错。
