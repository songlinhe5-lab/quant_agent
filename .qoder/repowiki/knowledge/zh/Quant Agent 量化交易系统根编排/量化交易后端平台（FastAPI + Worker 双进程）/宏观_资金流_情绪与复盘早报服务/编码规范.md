- 外部数据源调用统一采用 `try/except` 包裹并在异常时返回 `{status: 'error', message, data: None}` 或 None，由上层 `asyncio.gather(return_exceptions=True)` 汇总为 partial 状态。
- 长耗时数据采集使用 `asyncio.gather` 并发执行多个市场/标的任务，并对每个任务设置超时（如 `_COLLECT_TIMEOUT = 30.0`）防止单点阻塞。
- 对外部 API 结果先检查 `result.get('status') == 'success'` 再取值，字段名兼容多种形态（如 `last_price`/`price`、`change_pct`/`pct_change`）以适配不同上游。
- 关键数据写入 Redis 前进行安全过滤（如 FRED series_id 正则清洗）并配合 TTL + jitter 随机过期，避免脏数据长期锁定。
- LLM 输出通过 Pydantic model（如 `_LLMReviewAnalysis`）约束结构，系统提示词集中定义在模块顶部常量（`_ANALYSIS_SYSTEM_PROMPT`、`SYSTEM_PROMPT`、`MORNING_BRIEFING_PROMPT`）。
- 对“零幻觉”场景显式标记：当核心客观数据缺失时，复盘报告设置 `data_complete=False` 并注入固定警告文案，禁止 LLM 自由发挥填充定性结论。
