- 每个业务域以 services/<domain>/ 子包组织，对外暴露 service.py 中的单例对象供 routers 与 workers 调用
- 外部数据源统一实现 DataSourceInterface 协议并注册到 services/datasource/source_registry，由门面 facade 路由
- HTTP 路由层只负责参数校验与委派，不承载业务逻辑，业务用例集中在 app/*_app.py 或 services/* 中
- 异步后台任务通过 asyncio.create_task 启动并在 worker.py 中用 asyncio.gather 统一管理与优雅取消
- 数据库变更通过 alembic versions/*.py 迁移脚本管理，新表需在 main.py 启动时确保扩展与索引就绪
- 可观测性统一通过 core.logger (structlog)、core.metrics、core.otel_config 输出，禁止在各子模块内自建日志/指标
