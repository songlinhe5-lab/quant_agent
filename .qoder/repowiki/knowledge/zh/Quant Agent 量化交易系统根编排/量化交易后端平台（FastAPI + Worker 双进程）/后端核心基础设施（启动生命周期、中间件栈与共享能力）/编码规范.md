- 所有外部依赖（数据库、Redis、LLM、通知渠道）均通过 Pydantic Settings v2 从环境变量加载并在构造期 fail-fast 校验必填字段。
- 长生命周期对象（engine、async_engine、redis_client、redis_batch_writer、settings）以模块级单例形式导出，供各子模块直接 import 使用。
- 后台守护任务在 `app_lifespan` 启动阶段用 `asyncio.create_task` 拉起，在关闭阶段统一收集到 `tasks_to_await` 列表并以 `asyncio.wait_for(..., timeout=30.0)` 优雅取消，避免僵尸协程。
- 对第三方/外部服务的调用采用 try/except 包裹并记录 warning/error 日志，启动阶段失败不阻断主服务启动（降级跳过）。
- HTTP 中间件通过 `@app.middleware('http')` 或 `app.middleware('http')(fn)` 注册，并按“后注册先执行”的顺序组织链式处理逻辑。
- Redis 操作统一使用 `async with redis_client.pipeline() as pipe:` 进行原子批量写入，避免多次 RTT。
