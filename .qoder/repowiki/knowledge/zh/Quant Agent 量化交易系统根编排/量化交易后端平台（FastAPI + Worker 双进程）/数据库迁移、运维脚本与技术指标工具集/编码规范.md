- 脚本通过 `sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(__file__), "../..")))` 将仓库根加入 `sys.path`，再 `import backend.core.*` 获取模型与会话，避免依赖包安装路径。
- 每个运维脚本采用 `class XxxManager` 封装核心逻辑，并在模块末尾暴露 `async def main()` + `argparse` 子命令，最终由 `if __name__ == "__main__": asyncio.run(main())` 启动。
- Alembic 迁移文件统一在 `upgrade()`/`downgrade()` 中先通过 `sa.inspect(conn).get_table_names()` 检查表是否存在，再执行列增删，保证 SQLite 测试环境与生产 PG 均可安全运行。
- 配置全部来自环境变量（`os.getenv`），并提供默认值；敏感信息（R2 密钥、DB 密码）不硬编码，仅通过 `.env` 注入。
- 日志统一使用 `structlog.get_logger(__name__)`，关键步骤输出带 `[模块名]` 前缀的结构化日志，便于 grep 追踪。
- 技术指标函数以 `calculate_<indicator>(df: pd.DataFrame, period: int) -> dict|float` 为统一签名，返回最新值或包含多个指标的字典，便于策略代码一致调用。
