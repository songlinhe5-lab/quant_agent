- 对外服务类暴露全局单例实例（如 `deep_research_pipeline`、`rag_governance`、`eval_runner`、`get_expert_team_service`），便于上层直接 import 使用。
- LLM 调用统一通过 `ModelTier` 分级（STANDARD/FLAGSHIP）选择模型，并在失败时记录成功/失败计数用于路由降级。
- 异步 IO 中涉及同步数据库访问（SQLAlchemy engine/session）一律用 `asyncio.to_thread` 包装，避免阻塞事件循环。
- 外部依赖（Redis、PostgreSQL、ToolRegistry）采用延迟导入（方法体内 import），保证模块在无后端依赖时可被单独加载。
- 关键流程包含 try/except 降级路径：LLM 异常回退为原始数据片段、Redis/PG 不可用时回退到内存字典兜底。
- Prompt 与系统提示集中定义在文件顶部常量（SYSTEM_PROMPT/NARRATE_PROMPT）或 `prompts/*.md` 文件中，与业务逻辑解耦。
