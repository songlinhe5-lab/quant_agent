- 所有服务与 worker 均以模块级单例导出（如 `oms_service`、`paper_ledger_service`、`algo_engine`、`bot_runtime`、`paper_settlement_daemon`），调用方直接 import 使用。
- 对外部依赖（Futu 行情/下单、DataSourceRouter）采用延迟 import（函数体内 `from backend.services.datasource.router import data_source_router`），避免启动时强耦合。
- 异步方法统一通过 try/except 捕获异常并记录日志，失败时返回空结果或错误字典而非抛出，保证上层调用稳定。
- Redis 键采用命名空间前缀 `quant:oms:*` / `quant:paper:*`，并按业务域划分 Hash/List/Set，配合 TTL（如 300s、15s、7 天）自动过期。
- 状态变更（订单、算法、Bot、日志）均先写 Redis 再写 DB，或通过 Redis PubSub 广播给前端，形成缓存优先的读写路径。
- 幂等性通过 Redis NX 锁（结算）或数据库唯一约束 + IntegrityError 回滚重试（策略版本 save_version）实现。
