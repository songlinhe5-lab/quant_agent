- 主文档采用数字前缀命名（如 `01. 产品功能与UIUE架构.md`）以强制排序和快速定位。
- 子系统文档统一放置在 `docs/subsystems/<子系统名>/architecture.md`，每个子系统一个独立架构文件。
- 技术决策与评审以 ADR/Epic/Phase 形式归档于根目录（如 `ADR-007-*.md`、`EPIC-*.md`、`PHASE*_COMPLETION_REPORT.md`）。
- 数据源能力缺口与调研任务以 `TODO-<领域>.md` 形式单独成文，并在 README 中集中索引。
- 架构图使用 Mermaid 语法内嵌于 Markdown 中，便于在支持渲染的环境中直接查看。
