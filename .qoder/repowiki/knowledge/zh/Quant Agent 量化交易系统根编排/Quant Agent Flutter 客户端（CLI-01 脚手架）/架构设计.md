采用分层目录结构组织 lib：application（会话/连接健康/遥测生命周期）、domain（领域模型）、features（按业务特性划分的模块）、infrastructure（外部依赖封装）、platform（平台通道）、presentation（路由、主题、组件）以及 tooling（辅助工具）。入口 main.dart 通过 ProviderScope 启动 QuantAgentApp，使用 go_router 进行声明式导航，并以 ConnectionHealthSync → TelemetryLifecycle → PushLifecycle 的嵌套组合方式挂载 MaterialApp 和 AlertOverlayHost。依赖管理集中在 pubspec.yaml，Android/iOS/ohos 子目录分别承载各平台的原生工程与资源，test 目录下以 cliNN_ 前缀命名行为测试用例，design 目录维护 Figma Token 同步配置。
