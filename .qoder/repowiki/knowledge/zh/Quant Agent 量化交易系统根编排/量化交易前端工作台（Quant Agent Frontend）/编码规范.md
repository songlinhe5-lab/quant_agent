- 业务页面统一通过 `lazyWithRetry` 包装 `React.lazy` 动态 import，并配合 `<Suspense>` fallback 与 `ModuleErrorBoundary name="..."` 包裹，确保懒加载失败可降级与隔离。
- 跨模块共享状态采用 Zustand store 文件化组织，每个 store 独立文件并以 `useXxxStore` 命名导出 hook（如 useLayoutStore、useTradeStore、useSceneModeStore）。
- UI 组件遵循 Radix Headless + Tailwind 的组合模式，位于 `src/components/ui/`，并通过 `class-variance-authority` 定义 variants（如 badge-variants.ts、button-group-variants.ts）。
- 功能域按 `features/<domain>/` 目录聚合，每个 domain 内自包含 UI、store、hooks、types，并通过 `module.tsx` 或 `page.tsx` 暴露模块入口供路由懒加载。
- 全局上下文（主题、国际化、认证、确认对话框、Toast）在 `main.tsx` 中自上而下嵌套注入，业务组件通过 useContext 消费而非 props 透传。
- 网络与实时通信统一通过 `lib/api-client.ts` 与 `hooks/use-ws-manager.ts` 抽象，feature 层仅调用高层 hook，不直接操作 fetch/WebSocket。
