开发需启动后端服务监听 8000 端口，Vite dev server 会通过 proxy 将 /api、/ws、/sse 转发至 http://127.0.0.1:8000；构建命令 `pnpm build` 输出至 dist，并通过 Dockerfile 多阶段构建（NODE_OPTIONS --max-old-space-size=4096 防止 OOM）；性能基线通过 `pnpm lighthouse:baseline` 执行（默认 desktop preset，LIGHTHOUSE_FORM_FACTOR=mobile 可切换移动端）；测试覆盖 `pnpm test:coverage` 生成 coverage/ 报告。
