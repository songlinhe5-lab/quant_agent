### ReAct 单驱动收口
- 定义：Hermes Agent 内核架构优化 Phase 0 的核心任务：将 agent.py 中两套重复的 ReAct 主循环（非流式 `_step_loop` 与流式 `chat_stream_async`）合并为单一 driver，收敛 max_iterations、熔断恢复、schema 注入等逻辑，使后续中间件管线只需实现一次。
- 别名：AGENT-04、Phase 0

### 场景模式 (Scene Mode)
- 定义：前端全局工作区模式，包含盯盘 (watch)、研究 (research)、监控 (monitor)、AI (ai-analysis) 四种，通过导航栏 SceneModeSwitcher 切换，并在 localStorage 持久化（key: `quant_scene_mode`），不同场景自动联动右侧 Tab 与标题徽章。
- 别名：scene mode、useSceneModeStore、SCENE_META

### 个股工作台
- 定义：前端 `/quotes` 页面，采用三栏布局（K 线/盘口/微观），支持 Alt+D/M/C/O 快捷键快速切换视图，并可在微观卡中跳转所属板块资金流向。
- 别名：quotes module、portfolio workbench

### 数据源子服务 (Data Subservice)
- 定义：独立 FastAPI 节点，运行在远程 VPS 上作为第三方数据源提供者，通过 ServiceRegistry 向主服务注册并发送心跳保活；主服务经 DataSourceRouter 走 HTTP 调用，禁止在主服务内直连任何第三方数据源 SDK。
- 别名：data_subservice、DataSourceRouter

### DS_CAPABILITIES
- 定义：数据源子服务的运行时能力开关，决定哪些 worker（如 yfinance、futu、tushare）被加载；未声明的能力返回 503，用于按地域/节点能力隔离镜像，避免单镜像打全量 SDK。
- 别名：capabilities、node capability

### Token 计量埋点
- 定义：Agent 每次 LLM 调用后通过 `token_usage_store.record` 上报 prompt_tokens/completion_tokens/total_tokens，已抽取为统一的 `_record_usage` 辅助函数，覆盖非流式主循环、流式接收完毕、熔断恢复等多处路径。
- 别名：usage tracking、_record_usage

### SSE 事件契约
- 定义：Agent 流式对话通过 SSE 推送 NDJSON 事件，固定 8 种事件类型：text_chunk、reasoning_chunk、tool_result、heartbeat、strategy_code、chart_annotation、error、iteration_limit_reached，重构不得改变字段名。
- 别名：stream events、NDJSON 事件流

### AGENT-02 middleware seam
- 定义：工具执行入口 `_safe_execute_tool` 预留的横切挂点，未来在此插入审批闸门→失败熔断→结果分类→脱敏→缓存→限流的责任链，当前仅做 json.loads + execute + try/except。
- 别名：middleware seam、tool execution hook

### AGENT-11 Prompt 缓存边界
- 定义：计划中的 Token 成本计量与 Prompt 缓存优化任务，复用 `_record_usage` 作为统一挂点，用于增加成本计算与缓存命中率统计。
- 别名：prompt cache、token cost metering

### SVC-05 配额告警
- 定义：Finnhub 等外部数据源配额耗尽时的飞书告警机制，接入 OBS-02 监控体系，用于提醒运维及时扩容或切换数据源。
- 别名：quota alert、SVC-05
