- 所有服务通过 Docker Compose 的 `quant-internal` 桥接网络互联，外部端口仅绑定 loopback 或 TAILSCALE_IP，禁止直接暴露公网。
- 环境变量统一通过 `.env` 文件注入，数据库、Redis、OTEL 等连接参数在 master/node 系列 compose 中集中声明。
- 数据源 SDK 按架构规定仅安装在 data_subservice 节点，主服务通过 HTTP 路由转发，不在 backend 环境中 import。
- 监控与告警配置集中在 `prometheus.yml`、`config/prometheus_rules.yml`、`grafana/provisioning/*`，新指标需同步更新这些文件。
- 跨语言共享协议统一放在 `shared/proto/`，并通过 Makefile 与 package.json 脚本分别生成 Python 与 JavaScript/TypeScript 客户端。
