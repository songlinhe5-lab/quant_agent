本模块由三个 FastAPI `APIRouter` 组成：
- `market.py`（前缀 `/market`）：核心行情入口，通过 `_is_futu_ticker` 判断富途标的走 `data_source_router.fetch_futu` 单独通道，其余标的走 `backend.services.datasource.business.market_data_service` Facade；WebSocket `/quotes/ws` 使用 `manager.connect/subscribe/unsubscribe` 维护进程内订阅表，并通过 `asyncio.create_task` 异步回灌到 OpenD；健康检查 `/health/services` 聚合 Futu OpenD、AKShare、YFinance、DataSourceRouter、Finnhub/FRED 状态。
- `options.py`（前缀 `/options`）：纯计算型路由，依赖 `backend.app.market_data`、`backend.domain.options_engine.compute_option_chain_greeks` 与 `backend.services.screener.options_screener` 完成 Greeks、筛选、波动率微笑、IV Rank 与跨到期日矩阵计算。
- `calendars.py`（前缀 `/calendars`）：以 `CALENDAR_CATEGORIES` 配置驱动的多类目宏观快照，按 futu → Redis(`yf_macro_cache_*`)→ on-demand yfinance 三级降级，并使用进程内 `asyncio.Lock` 池防缓存击穿；分红/IPO 端点接入 Finnhub 并通过 `rate_limit_registry` 做限流退避。
依赖方向单向向下：路由层仅消费 `services/datasource`、`services/fund_flow`、`app/*` 等上层服务，不反向被业务逻辑引用。
