本模块由三个并列的 FastAPI `APIRouter` 组成，按职责拆分为风控与回测两条线：
- `risk.py`：注册 `/risk` 路由组，通过共享辅助函数 `_get_market_data` 统一从 `risk_engine.get_portfolio_risk()` 拉取持仓与 K 线数据，再委派给 `services.risk` 下的独立分析器（`sector_analyzer`、`decompose_cvar`、`liquidity_assessor`、`stress_tester`、`calc_attribution`），实现“路由薄 + 领域服务厚”的分层。
- `backtest.py`：注册 `/backtest` 路由组，将 Pydantic 请求模型（`BacktestRequest`、`WalkForwardRequest`、`MonteCarloRequest`、`GridSearchRequest`、`OverfitRequest`）映射到 `backend.app.*_app` 中的 `run_*` 入口；其中 `/run/stream` 使用 `asyncio.Queue` + `StreamingResponse` 以 NDJSON SSE 推送撮合进度；AI-03 解读功能通过模块级单例 `BacktestInterpreterService` 避免重复构造 LLM 客户端，并将健康度结果落盘至 `health_store`。
- `backtest_reports.py`：注册同前缀 `/backtest` 但 tag 为 `Backtest Reports` 的子路由，负责报告的 CRUD 与快照注册，依赖 `BacktestReportService`、`SnapshotResolver`、SQLAlchemy Session (`Depends(get_db)`) 完成持久化，并通过统一的 `_ok`/`_err` 包装响应体。
依赖方向单向向下：路由层仅做参数校验与异常转换（自定义 Error → HTTPException），业务计算全部委托给 `backend.services` 与 `backend.app` 子包。
