本模块按数据源拆分为四个并列子包，每个子包对外暴露一个 Service 类或单例：
- `akshare/`：采用 Mixin 组合模式（`__init__.py` 将 `FlowMixin`、`QuoteMixin`、`CalendarMixin` 混入基类），主服务通过 `DataSourceRouter` 远程调用 AKShare 子服务，本地仅维护 Redis 缓存、分布式锁与熔断状态；支持 `AKSHARE_MODE=cache` 的北京 VPS 中继模式。
- `finnhub/`：基于 `httpx.AsyncClient` 直连 Finnhub REST API，内置代理池轮换、Redis 多级缓存（财报日历/历史K线/新闻等 TTL 不同）、SVC-08 全局限流退避引擎（区分 429/403/402），并在新闻接口失败时回落到 Yahoo Finance 非官方搜索接口；`ws_ingest.py` 作为 BE-ARCH-07 薄代理委托给 `backend.services.datasource.subscription` 订阅 Redis tick 频道。
- `fmp/`：纯薄壳，优先经 `data_source_router` 调子服务 `_internal/fmp`，失败或未启用时降级为本地 `httpx.get` 直连，保持 `get_quote/get_profile/get_income_statement` 签名不变。
- `tushare/`：`service.py` 实现 A 股主源封装（含令牌桶限速分组：finance 80rpm、default 200rpm），`adapter.py` 将其适配为 `DataSourceInterface`（`capabilities` 声明 stock_history/quote/fundamental/fund_flow 等），由 `ensure_tushare_registered` 幂等注册到 `datasource_registry`，主节点无 tushare SDK 时自动跳过本地注册走 HTTP 路由。
依赖方向单向向外：各 Service → 第三方 SDK/HTTP 客户端 + `backend.core.redis_client` + `backend.core.circuit_breaker` + `backend.services.datasource`（限流/结果模型），不反向被业务代码直接耦合。
