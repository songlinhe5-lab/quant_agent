本模块由五个相互协作的子包构成，围绕 LLM 调用与金融研究任务组织：
- `services/ai_narrator/`：异动解说服务，通过 ToolRegistry 并发拉取公司新闻与基本面数据，经 Prompt 模板压缩后交由 `LLMService`（支持 ModelTier 分级与降级）生成一句话解说，并内置配额监控与 token 用量存储。
- `services/expert_team/`：专家团辩论服务，以 `ExpertTeamService` 为对外入口封装 `DebateOrchestrator`，按场景加载 `prompts/` 下的 Markdown 提示词（finance/code/chief_analyst），通过 SSE 流式返回事件；会话采用 Redis 热缓存 + PostgreSQL 冷存储 + 内存兜底的双层持久化策略。
- `app/research/deep_research.py`：三段式研报流水线（ClusterDiscoveryAgent → DataDeepDiveAgent → ChartDeliveryAgent），顺序编排聚类发现、深度分析与 Markdown/ECharts 交付，依赖 `llm_service` 的 Pydantic 结构化输出与 FLAGSHIP 模型。
- `app/rag/governance.py`：RAG 知识库治理，负责 embedding 模型版本检测与全量重建、检索相似度连续低分告警，所有 DB 操作通过 `asyncio.to_thread` 在同步 SQLAlchemy 引擎上执行以避免阻塞。
- `app/eval/runner.py`：基于 `golden_dataset.json` 的评估运行器，按 metric_type 路由到 `EvalMetrics` 对应指标函数，产出 EvalReport 供 CI 或本地验证使用。
依赖方向：research/eval 依赖 ai_narrator 的 llm_service；expert_team 独立管理自身 prompts 与持久化；rag 仅依赖 core.config/database/redis_client；各子包之间无横向耦合，统一通过 hermes_agent 的 ToolRegistry 接入外部工具。
