模块以 `event_engine.py` 为对外入口，暴露 `EventDrivenBacktestEngine`（逐 K 线撮合：限价挂单簿 `pending_orders`、动态止损、滑点与手续费磨损）和 `run_dynamic_sandbox_backtest`（动态策略执行入口）。后者在 debug_mode 下强制降级到事件驱动引擎，否则走 `runners.py` 中的 Numba/VectorBT 矢量化路径：通过 `_drive_strategy` 统一适配两种策略契约——类方法 `_calculate_indicators`/`_generate_signals`（dense 编码）与模块级 `generate_signals(df)`（event 编码），再由 `_signal_entries_exits` 转换为 VectorBT 的 entries/exits 序列。

`sandbox.py` 提供独立的安全层：AST 扫描 (`SandboxSecurityVisitor`) 拦截危险函数/魔术属性/递归/while 循环/超大 range；白名单导入 (`allowed_modules`) + 运行时 `__import__` 钩子 (`_safe_import`) 拦截高危底层模块；`SAFE_BUILTINS` 剥离 eval/exec/open/compile；`strip_numba_cache_source` 移除 numba 装饰器的 cache 参数以避免临时源码缓存失败；`SandboxTimeoutTracer` 基于 `sys.settrace` 实现超时与可选 psutil 内存熔断；`BaseStrategySandbox` 定义策略基类桩。

`runners.py` 复用 sandbox 能力实现三类批处理场景：`run_grid_search_backtest`（笛卡尔积参数网格）、`run_monte_carlo_stress_test`（对 Close/OHLC 注入 Laplace/t/高斯噪声并重复运行）、`run_batch_sandbox_backtest`（多标的横截面批量回测，按 ticker 聚合 Portfolio）。

`strategies.py` 内置 `DivergenceResonanceStrategy`（RSI/MACD/KDJ 背离共振 + ATR 追踪止损），作为可被沙箱加载的参考实现，同时展示 dense 信号编码约定。

依赖方向单向：`event_engine.py` → `runners.py` → `sandbox.py`；`strategies.py` 仅依赖 `sandbox._safe_stat`，不反向依赖引擎。
