- 每个脚本以独立的 `if __name__ == "__main__": main()` 形式组织，便于直接 `python3 scripts/<script>.py` 执行。
- 对外部数据源的诊断集中在 `probes/` 目录，并通过 `README.md` 表格维护脚本清单，明确标注直连的数据源与用途。
- 验证类脚本统一输出结构化报告（JSON 或带分隔线的文本块），便于被 CI 或 cron 解析与归档。
- Shell 脚本采用命名前缀区分用途：`verify_*.sh` 做健康检查，`setup_*.sh`/`init_*.sh` 做环境初始化，`registry-gc.sh` 做资源回收。
- 启动/编排脚本通过 `subprocess.Popen` 拉起子进程，并在 `finally` 块中统一终止子进程与关闭日志句柄，保证退出时资源清理。
- 对端口占用等系统级状态，优先用 `socket` 探测后再调用 `lsof`/`kill` 清理，避免竞态导致启动失败。
