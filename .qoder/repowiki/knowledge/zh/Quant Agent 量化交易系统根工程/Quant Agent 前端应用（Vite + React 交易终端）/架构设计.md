应用以 `src/main.tsx` 为入口，通过 `BrowserRouter` 挂载 `App`，外层包裹 `ModuleErrorBoundary`、`ThemeProvider`、`I18nProvider`、`AuthProvider` 等全局上下文；路由集中在 `src/App.tsx`，所有业务页面均通过自定义的 `lazyWithRetry` 包装 `React.lazy` 实现按路由懒加载，并在 ChunkLoadError 时自动刷新避免白屏。

代码按领域划分：`features/` 下每个子目录对应一个业务域（trading、quotes、screener、strategy、backtest、oms、risk、copilot、research、paper、alert、calendars、briefing、data-center、system、settings 等），每个 feature 内部再组织 UI、store、hooks、types；共享能力下沉到 `components/`（含 `ui/` Radix 原子组件与 `layout/` 布局组件）、`hooks/`、`stores/`（Zustand 状态管理）、`contexts/`（auth、i18n）、`lib/`（API 客户端、格式化、日志、kline 缓存、web-vitals）、`workers/`（Web Worker 计算指标）、`types/`、`locales/`。

构建与部署：`vite.config.ts` 配置了 `@` 路径别名、Vitest 测试环境（jsdom + v8 覆盖率）、开发代理（/api、/ws、/sse → 127.0.0.1:8000）以及 sourcemap；Dockerfile 使用多阶段构建（node:20-alpine 构建 + nginx:alpine 静态托管）；`wrangler.toml` 支持 Cloudflare Pages SPA 路由重定向与资源缓存；`scripts/lighthouse-baseline.mjs` 配合 `.lighthouse/baseline.*` 报告做性能基线校验。
