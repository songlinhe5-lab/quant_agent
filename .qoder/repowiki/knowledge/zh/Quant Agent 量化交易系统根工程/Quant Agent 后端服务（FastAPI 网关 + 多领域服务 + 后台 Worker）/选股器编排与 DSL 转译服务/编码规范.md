- HTTP 编排函数统一接收 Pydantic 模型参数，并在 try/except 中将业务异常转换为 `AppError(status_code, detail)` 返回，保持 router 层零业务逻辑。
- 所有耗时 I/O（SQL 查询、CSV 读取、Embedding 计算）通过 `asyncio.to_thread` 包装同步函数执行，避免阻塞异步事件循环。
- 对外部 LLM/第三方 API 的调用采用「重试 + 降级」模式：先尝试 LLM 输出并通过 Pydantic 预验证，失败时拼接错误信息反馈给模型自修复，最终仍失败则返回硬编码兜底 JSON。
- Redis 缓存键统一遵循 `quant:screener:*` 命名空间，并配合 `random.randint` 引入 TTL Jitter 防止雪崩；热点 DSL 同时使用内存 `asyncio.Lock` 做防重复计算。
- Mixins 内部通过 `getattr(self, '_embed_func', None)` 等惰性属性探测能力开关，当 pgvector/Embedding 不可用时优雅降级为全量规则或空结果，不抛出异常。
- 数据库操作一律通过 `SessionLocal()` 上下文管理器隔离，并在 Daemon 中序列化 ORM 对象为轻量字典后再跨线程传递，避免 SQLAlchemy 对象泄漏。
