本模块由三个相互独立但共享项目根路径的子系统组成：
- `alembic/`：Alembic 迁移目录，`env.py` 通过 `sys.path.insert(0, ../..)` 将项目根加入导入路径并加载 `.env`，从 `backend.core.models`、`backend.core.datalake_models`、`backend.services.fund_flow.ticker.TickerItem` 导入所有 SQLAlchemy 模型以驱动 autogenerate；每个文件位于 `versions/` 下，命名遵循 `<feature_id>.py`（如 `ai04rag_add_rag_governance.py`），并通过 `revision`/`down_revision` 维护迁移链。
- `scripts/`：面向运维的一键式 CLI 脚本集合，每个脚本自包含 `argparse` 子命令入口并以 `asyncio.run(main())` 启动；依赖通过 `sys.path.insert(0, ...)` 注入项目根后直接 import `backend.core.database.SessionLocal`、`backend.core.models` 等核心对象；按职责划分：`pg_backup.py`/`redis_backup.py` 负责数据持久层备份与 R2 上传，`backup_restore.py` 实现灾难恢复演练（RTO < 2h），`migrate_knowledge_base.py` 提供 pgvector 知识库的 JSONL 导出/导入/清理，`benchmark_kline_pipeline.py`/`diagnose_tme_history.py`/`verify_vector_db.py` 用于性能与诊断。
- `utils/`：纯函数式技术指标库，基于 pandas/numpy 实现 ADX/DMI、CCI、VWMA、ATR%、Elder-Ray、Keltner Channels 等，无外部状态，可被策略或回测模块直接调用。
依赖方向单向指向 `backend.core.*`（模型、数据库会话）和第三方库（boto3、structlog、sqlalchemy），不反向依赖业务服务。
