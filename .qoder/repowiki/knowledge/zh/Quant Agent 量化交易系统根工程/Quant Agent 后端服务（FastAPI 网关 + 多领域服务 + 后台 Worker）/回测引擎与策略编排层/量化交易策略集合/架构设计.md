模块按用途划分为两个子目录：`live/` 存放可部署的生产级策略，`drafts/` 存放实验性草稿。核心依赖方向单向指向 `backend.backtest.BaseStrategySandbox`，所有生产策略（如 `DualMaAtrStopStrategy`、`MaCrossAtrStrategy`）均通过继承该基类并重写 `_calculate_indicators` 与 `_generate_signals` 两个钩子方法来实现指标计算与信号生成；`pairstradingbot.py` 中的 `PairsTradingBot` 为独立实现的 Z-Score 均值回归策略，不依赖基类，采用 `on_tick` 事件驱动接口。策略内部使用 pandas/numpy 对 OHLCV 数据框进行向量化计算，ATR 通过 True Range 滚动平均推导，信号以 `signal` 列写入数据框供引擎执行。
