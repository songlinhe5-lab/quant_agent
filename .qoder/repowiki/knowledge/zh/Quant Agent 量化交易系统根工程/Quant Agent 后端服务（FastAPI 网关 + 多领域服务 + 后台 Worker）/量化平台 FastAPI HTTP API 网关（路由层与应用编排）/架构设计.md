本模块是后端对外暴露的 HTTP/WS 网关：main.create_app() 在启动时依次注册全局中间件（AccessLog、CORS）、异常处理器、OpenAPI 标签与 OTEL，然后按功能域把 routers/* 下的子路由全部 include_router(prefix='/api/v1')，根级仅保留 system_health、mcp 等基础设施路由。
- 路由层（routers/）按业务域拆分为行情期权、投资组合交易、投研因子、风控回测、系统管理、数据源/数据湖六大子模块，每个文件只负责参数校验与调用 app 层，不承载业务编排。
- 应用编排层（backend/app/）提供 market_data、broker 等 Port 门面以及 oms_app、backtest_app、system_app、walk_forward_app、monte_carlo_app、grid_search_app、overfit_app 等用例入口，被各 router 统一 import 调用，形成「router → app_* → services/domain」的单向依赖链。
- schemas/domain.py 作为跨路由共享的 Pydantic 模型定义，供多个 router 复用；core/ 中的 exception_handlers、middleware、openapi_schema、otel_config 由 create_app 集中装配，所有路由共享同一套鉴权、限流、审计与可观测性能力。
- 运行时通过 bootstrap.lifecycle.app_lifespan 完成全局 LLM 客户端与服务注册表初始化，确保所有路由在请求进入前已就绪。
