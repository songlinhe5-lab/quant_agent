- 每个文件顶部定义一个 `APIRouter(prefix=..., tags=[...])` 实例，集中声明一组相关端点并按功能划分路由组。
- 请求参数统一用 Pydantic `BaseModel` 描述，字段通过 `Field(default_factory=...)`、`ge/le/pattern` 等约束进行入参校验。
- 业务调用封装在 `try/except` 中，将领域自定义异常（如 `BacktestDataError`、`GridSearchError`）转换为 `HTTPException(status_code=400)`，保持路由层不向上抛出业务异常。
- 风控端点对空账户状态采用“返回空结构 + 200”而非抛错（如 `positions is None` 时返回零值字典），仅真正的系统错误才抛 500。
- 对耗时/外部依赖操作采用懒加载导入（如 `from backend.app.market_data import market_data`、`from backend.services.backtest_interpreter.health_store import ...`）以避免启动时循环依赖。
- 报告类接口统一通过 `_ok`/`_err` 包装响应体，包含 `status`、`message`、`data`、`timestamp` 字段，保证前端一致的消费契约。
