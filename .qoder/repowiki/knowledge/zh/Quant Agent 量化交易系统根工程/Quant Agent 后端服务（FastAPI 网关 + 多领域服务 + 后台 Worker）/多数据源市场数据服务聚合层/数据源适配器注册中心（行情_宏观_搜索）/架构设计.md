本模块是 datasource 子系统的适配器层，所有文件均实现 DataSourceInterface（name/version/capabilities/is_available/health/fetch），并通过各自 ensure_*_registered() 函数在 __init__.py 的 ensure_all_datasources_registered() 中按权重顺序集中注册。
- 核心行情源（futu.py、legacy_yfinance.py、finnhub.py、fmp.py）：每个文件定义一个 DataSource 类 + ensure_*_registered()，通过 data_source_router.fetch_xxx() 远程调用 data_subservice，不持有本地 SDK；is_available/health 直接读取 router._nodes 中对应节点状态。
- A 股/宏观源（akshare.py、tushare.py、macro.py）：采用基类模式——macro.py 提供 _RemoteMacroDataSource，search.py 提供 _RemoteSearchDataSource，具体源仅声明 source_key/name/capabilities，复用健康检查与 fetch 封装。
- 搜索抓取源（search.py）：Tavily/Bocha/Jina 经 data_source_router.fetch_search() 走 data_subservice 代理，capabilities 使用 WEB_SEARCH / WEB_SCRAPE 自定义 action。
- 依赖方向单向向外：adapter → backend.services.datasource.router（data_source_router）→ data_subservice HTTP；adapter 不反向依赖子服务实现，仅依赖 router 暴露的节点元信息做健康探测。
- 注册入口 __init__.py 按业务分组（核心行情 → A 股/宏观 → 宏观 FRED/DBnomics/RBI → 搜索抓取）依次 try/except 调用各 ensure_*，失败仅记录 warning 不影响整体启动。
