模块以 `protocol.py` 的 `DataSourceInterface`（Protocol）为唯一抽象边界，所有具体数据源适配器位于 `adapters/`，业务编排层位于 `business/`，通过 `router.py` 的 `DataSourceRouter` 将请求转发到远程 data_subservice 子服务节点（YFinance/Tushare/AKShare/Futu/FMP/Finnhub/宏观/搜索），不再本地直连 SDK。

- 协议与模型：`protocol.py` 定义 `DataSourceInterface`；`__init__.py` 集中导出 `ErrorCategory`、`ErrorInfo`、`RateLimitInfo`、`Result`、`ResultStatus`、`HealthInfo`、`RateLimitStatus` 等统一数据结构，并暴露 `classify_http_error` / `parse_retry_after` 错误分类工具。
- 限流与熔断三件套：`throttler.py` 的 `RateLimitThrottler` 实现 none/linear/exponential/adaptive 四种退避策略，按 ErrorCategory 区分瞬时限流（指数退避+自愈）与硬失败（配额耗尽/IP封禁固定窗口抑制）；`analyzer.py` 的 `RateLimitAnalyzer` 基于 24h 事件序列推测 RPM、高峰时段、推荐间隔与平均恢复时间；`registry.py` 的 `RateLimitRegistry` 以单例形式按 source_name 管理 Throttler + Analyzer 对。
- 路由与熔断：`router.py` 维护多个 `DataSourceNode`（yf_primary/yf_backup_*、akshare_remote、tushare_remote、futu_master、fmp_master、finnhub_master、fred_master、dbnomics_master、rbi_master、search_master），通过 HMAC-SHA256 签名调用 `/api/v1/data`，实现 action→子服务 action 映射、健康探针半开自愈、action 级熔断隔离（`_ACTION_MAX_FAILURES` + 动态节点阈值 `_node_breaker_threshold`）与节点级兜底熔断。
- 辅助组件：`subscription.py`、`alert_monitor.py`、`health_monitor.py`、`probe_daemon.py`、`call_metrics_store.py`、`offline_stub.py`、`source_registry.py` 分别处理订阅、告警、健康检查、探针守护、Redis 调用计数、离线 stub 与源实例注册。
依赖方向：business → router → (throttler/analyzer/registry) → protocol/__init__；adapters 仅依赖 protocol，不反向依赖 router。
